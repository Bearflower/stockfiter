# 如何修改系统执行时间

## 📝 概述

系统默认每小时执行一次行情分析和信号检测。你可以通过简单的命令修改执行时间，不需要重新打包或构建镜像。

---

```bash
ssh root@43.156.242.184 "cd /root/bianace_btcethbnb_trade && ./set_schedule_time.sh <分钟数>"
```

## 📋 手动修改（高级）

如果你想手动修改配置文件，可以按照以下步骤：

### 步骤 1：SSH 登录服务器

```bash
ssh root@43.156.242.184
```

### 步骤 2：编辑配置文件

```bash
nano /root/bianace_btcethbnb_trade/config/scheduler_config.yaml
```

### 步骤 3：修改分钟数

```yaml
# 调度器配置文件

# 每小时分析任务的执行时间配置
hourly_analysis:
  # 分钟数（0-59）
  # 例如：25 表示每小时的 25 分执行（00:25, 01:25, 02:25, ..., 23:25）
  minute: 25  # 修改这里

# 每日报告发送时间配置
daily_report:
  hour: 9
  minute: 10
```

### 步骤 4：保存并退出

按 `Ctrl+O` 保存，按 `Enter` 确认，然后按 `Ctrl+X` 退出。

### 步骤 5：复制配置文件到容器

```bash
docker cp /root/bianace_btcethbnb_trade/config/scheduler_config.yaml binance-trade-analyzer:/app/config/scheduler_config.yaml
```

### 步骤 6：重启容器

```bash
docker restart binance-trade-analyzer
```

### 步骤 7：验证配置

```bash
docker logs binance-trade-analyzer --tail 20 | grep "每小时执行分钟数"
```

应该能看到类似这样的输出：
```
2026-04-22 09:03:16,790 - scheduler_new - INFO - 每小时执行分钟数：5
```

## 🔧 配置文件说明

配置文件路径：`/root/bianace_btcethbnb_trade/config/scheduler_config.yaml`

```yaml
# 调度器配置文件

# 每小时分析任务的执行时间配置
hourly_analysis:
  # 分钟数（0-59）
  # 例如：25 表示每小时的 25 分执行（00:25, 01:25, 02:25, ..., 23:25）
  minute: 25

# 每日报告发送时间配置
daily_report:
  hour: 9      # 小时（0-23）
  minute: 10    # 分钟（0-59）
```

### 配置项说明

| 配置项 | 说明 | 取值范围 | 默认值 |
|--------|------|----------|--------|
| `hourly_analysis.minute` | 每小时分析的分钟数 | 0-59 | 25 |
| `daily_report.hour` | 每日报告发送的小时数 | 0-23 | 9 |
| `daily_report.minute` | 每日报告发送的分钟数 | 0-59 | 10 |

## ✅ 验证配置是否生效

### 方法 1：查看日志

```bash
docker logs binance-trade-analyzer --tail 20 | grep "每小时执行分钟数"
```

### 方法 2：查看配置文件

```bash
docker exec binance-trade-analyzer cat /app/config/scheduler_config.yaml
```

### 方法 3：等待下一次执行

修改配置后，等待到下一个执行时间点，查看日志确认是否按时执行：

```bash
# 查看最近的执行日志
docker logs binance-trade-analyzer --since 1h | grep "每小时行情分析和信号检测"
```

---

## 📝 注意事项

1. **分钟数范围**：必须是 0-59 之间的整数，超过会报错
2. **重启容器**：修改配置后必须重启容器才能生效
3. **错过执行时间**：如果修改配置时已经错过了当前小时的执行时间，会等到下一个小时才执行
4. **日报时间**：每日报告默认在 09:10 发送，也可以通过配置文件修改

## 🔍 故障排查

### 问题 1：修改配置后没有生效

**原因**：容器内的配置文件没有更新

**解决方法**：
```bash
# 重新复制配置文件到容器
docker cp /root/bianace_btcethbnb_trade/config/scheduler_config.yaml binance-trade-analyzer:/app/config/scheduler_config.yaml

# 重启容器
docker restart binance-trade-analyzer
```

### 问题 2：日志显示旧的配置

**原因**：容器没有重启，或者重启的是旧容器

**解决方法**：
```bash
# 确认容器名称
docker ps | grep binance

# 重启正确的容器
docker restart binance-trade-analyzer

# 查看日志确认
docker logs binance-trade-analyzer --tail 20 | grep "每小时执行分钟数"
```

### 问题 3：脚本执行失败

**原因**：脚本没有执行权限

**解决方法**：
```bash
# 添加执行权限
chmod +x /root/bianace_btcethbnb_trade/set_schedule_time.sh

# 再次执行
./set_schedule_time.sh 05
```
