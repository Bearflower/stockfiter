# BTC/ETH/BNB 交易系统 - 通用模块使用说明

## 📦 已提取的通用模块

### 1. 通知服务模块

**模块位置**: `utils/lark_notifier.py`  
**通用服务**: `common_service/notification_service`  
**服务地址**: `http://43.156.242.184:8766/api/v1`  
**项目标识**: `btc_eth_bnb`

**改造说明**:
- 保持原有接口不变，确保向后兼容
- 内部实现改为调用通用通知服务
- 支持多种通知级别（info/warning/error）

**调用方式**:
```python
from utils.lark_notifier import LarkNotifier

notifier = LarkNotifier()

# 发送文本消息
notifier.send_text_message(
    content="分析任务完成",
    level='info'  # info, warning, error
)

# 发送成功通知
notifier.send_success_notification(
    currency="BTCUSDT",
    report_path="/path/to/report.md",
    screenshot_path="/path/to/screenshot.png"
)

# 发送错误通知
notifier.send_error_notification(
    currency="BTCUSDT",
    error_message="分析失败"
)

# 或使用便捷函数
from utils.lark_notifier import notify_completion, notify_error
notify_completion("BTCUSDT", "/path/to/report.md", "/path/to/screenshot.png")
notify_error("BTCUSDT", "分析失败")
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `btc_eth_bnb`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ 向后兼容，接口不变

### 2. K 线数据服务

**模块位置**: `utils/kline_service.py`  
**通用服务**: `common_service/kline_service`  
**服务地址**: `http://43.156.242.184:8765/api/v1`

**改造说明**:
- 封装对通用 K 线服务的调用
- 提供统一的接口
- 支持多种数据获取方式

**调用方式**:
```python
from utils.kline_service import KlineServiceClient, get_klines, get_indicators

# 方式 1: 使用客户端类
client = KlineServiceClient()

# 获取最新 K 线数据
klines = client.get_latest_klines(
    symbol="BTCUSDT",
    interval="1h",
    limit=100
)

# 获取技术指标
indicators = client.get_indicators(
    symbol="BTCUSDT",
    interval="1h",
    period=100
)

# 获取支持的币种列表
symbols = client.get_symbols()

# 手动触发 K 线采集
result = client.manual_collect(
    symbol="BTCUSDT",
    interval="1h",
    minutes=5
)

# 获取采集器统计信息
stats = client.get_collector_stats()

# 方式 2: 使用便捷函数
klines = get_klines("BTCUSDT", "1h", limit=100)
indicators = get_indicators("BTCUSDT", "1h", period=100)
```

**数据格式**:
```python
# K 线数据格式
[
    {
        'timestamp': '2026-04-27T10:00:00',
        'open_price': 95000.00,
        'high_price': 96000.00,
        'low_price': 94000.00,
        'close_price': 95500.00,
        'volume': 1234.56,
        'price_change_percent': 1.5
    },
    ...
]
```

**优势**:
- ✅ 统一的 K 线数据格式
- ✅ 支持多时间框架（1d, 4h, 1h, 15m）
- ✅ 自动采集和缓存
- ✅ 支持手动触发采集
- ✅ 提供采集器统计信息
