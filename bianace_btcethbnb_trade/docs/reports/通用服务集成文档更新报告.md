## 📋 代码变更概览

### 1. 飞书通知改造

**文件**: `utils/lark_notifier.py`

**改造内容**:
- 保持原有接口不变，确保向后兼容
- 内部实现改为调用通用通知服务
- 通用服务地址：`http://43.156.242.184:8766/api/v1`
- 项目标识：`btc_eth_bnb`

**主要方法**:
- `send_text_message(content, level)` - 发送文本消息
- `send_success_notification(currency, report_path, screenshot_path)` - 发送成功通知
- `send_error_notification(currency, error_message)` - 发送错误通知
- `send_analysis_result_notification(currencies, report_content)` - 发送分析结果通知
- `send_scheduler_startup_notification(next_run_time, timezone)` - 发送调度器启动通知
- `send_scheduler_shutdown_notification(timezone)` - 发送调度器关闭通知

### 2. K 线数据获取改造

**文件**: `core/data/fetcher.py`

**改造内容**:
- 使用 `KlineServiceClient` 调用通用 K 线服务
- 通用服务地址：`http://43.156.242.184:8765/api/v1`
- 支持并发获取多个交易对数据
- 支持多时间框架（1d, 4h, 1h, 15m）

**新增模块**: `utils/kline_service.py`

**主要方法**:
- `get_latest_klines(symbol, interval, limit)` - 获取最新 K 线数据
- `get_indicators(symbol, interval, period)` - 获取技术指标
- `get_symbols()` - 获取支持的币种列表
- `manual_collect(symbol, interval, minutes)` - 手动触发 K 线采集
- `get_collector_stats()` - 获取采集器统计信息

### 3. 环境变量配置

**文件**: `.env.example`

**新增配置**:
```bash
# 通用服务配置
KLINE_SERVICE_URL=http://43.156.242.184:8765/api/v1
NOTIFICATION_SERVICE_URL=http://43.156.242.184:8766/api/v1
NOTIFICATION_PROJECT=btc_eth_bnb

# 飞书通知配置（已废弃，使用通用通知服务）
# LARK_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/your_webhook_url
```
