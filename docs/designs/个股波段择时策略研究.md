## 1. 策略概述

针对伊利股份"**长期横盘震荡、单边下跌期长**"的特征，设计**上升趋势中的回调买入**波段策略：

- **核心逻辑**：只在均线多头排列（MA20 > MA60，中期趋势向上）时，捕捉 RSI 超卖（短期回调到位）的买点。
- **本质**：熊市自动空仓自保，牛市做回调买入，赚波段差价。
- **定位**：低波动辅助收益（全期年化约 3.5%），非主策略。

## 2. 策略规则

### 2.1 指标参数

| 指标 | 参数 | 说明 |
|------|------|------|
| RSI 周期 | 10 | 短期动量（Wilder 平滑） |
| RSI 超卖阈值 | 30 | 跌破 30 视为回调到位 |
| RSI 超买阈值 | 70 | 上穿 70 视为反弹到位 |
| 短期均线 MA20 | 20 日 | 趋势过滤 |
| 长期均线 MA60 | 60 日 | 趋势过滤 |
| 止损 | -8% | 跌破买入价 × 0.92 止损 |

### 2.2 买入信号（两个条件同时满足）

```
① 趋势过滤：MA20 > MA60（均线多头排列，中期趋势向上）
② 回调到位：RSI(10) 由 ≥30 跌破 30（当日收盘确认）
```

### 2.3 卖出信号（任一触发）

```
① 指标止盈：RSI(10) 由 ≤70 上穿 70（反弹到位）
② 硬止损：股价跌破买入价 × 0.92
```

### 2.4 执行时序（避免前视偏差）

```
T 日 15:00 收盘 → 用收盘价算 RSI/MA，确认信号
T 日晚间挂单（限价单/条件单）
T+1 日开盘（或集合竞价）成交
```

> RSI 是"收盘后才确定"的日线指标，**不能盘中实时交易**（盘中 RSI 随价格漂移）。正确用法是收盘后算一次，次日执行。

### 2.5 成本口径（复用 OBPC）

| 项目 | 费率 |
|------|------|
| 佣金 | 0.025% 双边 |
| 印花税 | 2023-08-28 前 0.1% 卖出，该日起 0.05% 卖出 |
| 滑点 | 0.1% 双边 |
| **合计** | **约 0.35%（旧）/ 0.30%（现行）每次完整交易** |

## 6. 风险提示

1. **样本量小**：仅 8 笔交易，87.5% 胜率统计意义有限，真实胜率可能在 60-80% 区间波动。
2. **资金效率低**：前 4 年（2020-2023）空仓，资金闲置，全期年化仅 3.5%。
3. **复权口径**：必须用**前复权**数据算指标。不复权数据在除权除息日有假跳空（伊利 2020-10-30、2022-10-28 等），会把分红误判为暴跌，导致收益率严重失真。
4. **单标的依赖**：策略只对伊利这一只票验证过，不能直接外推到其他股票。
5. **成本敏感**：旧报告中的年化 3.5% 尚待重算；实际换手成本会侵蚀收益，且历史与现行印花税不同。

## 7. 实盘操作流程（每日收盘后约 5 分钟）

1. **获取数据**：收盘后（15:00 后）获取伊利前复权日线，追加当日收盘价。
2. **算指标**：计算 RSI(10)、MA20、MA60。
3. **判断买入**：若 `MA20 > MA60` 且 `RSI(10) 今日跌破 30` → 触发买入信号。
4. **判断卖出**（若持仓）：若 `RSI(10) 今日上穿 70` 或 `收盘价 < 买入价 × 0.92` → 触发卖出信号。
5. **执行**：信号日当晚挂单，次日开盘/集合竞价成交。
