## 1. 产品概述

### 1.1 背景

OBPC 超跌反弹回踩确认策略 V2.0（代码版本 v25）在完成"60 日均线过滤 + 单月信号上限 + 动态评分阈值"三层风控增强后，重新执行 2020-01-01 ~ 2026-04-07 的回测，结果如下：

| 指标 | V2.0 预期 | V2.0 风控增强后实际 | 偏差 |
|------|----------|-------------------|------|
| 总信号数 | 28 | 117（被单月上限拦截 83 个，最终成交 34 笔） | 信号产出依然过多 |
| 胜率 | 67.9% | 20.59% | -47.31pp |
| 平均收益 | 3.28% | -4.29% | -7.57pp |
| 硬止损笔数 | - | 10 笔（占 29.4%） | 仍然偏高 |
| 60 日均线过滤命中 | - | 0 次 | **风控完全失效** |

**核心问题**：V2.0 风控增强后，全部 34 笔交易依然集中在 2026 年（系统性下跌期），60 日均线过滤命中 0 次，说明 2026 年初大盘指数收盘价始终位于 60 日均线上方，但市场实际处于系统性下跌状态。

### 1.2 根本原因分析

通过对 V2.0 回测数据与 2026 年初大盘走势的对照分析，定位到根本原因：

**60 日均线无法识别"均线之上但仍在下跌"的市场状态。**

具体表现为：
1. **均线滞后性**：60 日均线是过去 60 个交易日的平均收盘价，当指数从高位回落但尚未跌破 60 日均线时，均线过滤条件 `index_close >= MA60` 依然成立，导致风控无法触发；
2. **缺少动量判断**：仅用"价格 vs 均线位置"判断趋势，无法捕捉"价格仍在均线上方但动量已经转负"的拐点信号；
3. **缺少均线方向判断**：即使价格在均线上方，若均线本身已向下拐头，市场实际已转弱，但当前逻辑无法识别；
4. **评分系统未考虑大盘环境**：个股评分仅基于形态特征（跌幅/缩量/放量/回踩/支撑），未引入大盘相对强度调整，导致弱势市场下个股评分虚高。

**典型场景**：2026 年 1-3 月，沪深 300 从高位回落，但因其前 60 日包含大量高位数据，60 日均线仍维持上行或走平，指数收盘价始终在均线上方，V2.0 的 60 日均线过滤完全失效，117 个信号全部通过大盘趋势过滤，仅靠单月上限（12 个/月）拦截了 83 个，剩余 34 个信号全部成交并大幅亏损。

### 1.3 业务目标

| 优先级 | 目标 | 衡量指标 |
|--------|------|---------|
| P0 | 识别"均线之上但仍在下跌"的市场状态 | 该状态下信号产出数 ≤ 5 个 |
| P0 | 提升系统性下跌期的胜率 | 2026 年 1-3 月胜率 ≥ 45% |
| P0 | 提升整体回测胜率 | 全区间胜率 ≥ 45% |
| P0 | 提升整体平均收益 | 全区间平均收益 ≥ 0%（盈亏平衡） |
| P1 | 控制硬止损笔数 | 硬止损笔数占总交易数 ≤ 20% |
| P1 | 保持策略信号产出能力 | 年均信号数 ≥ 4 个 |
| P2 | 引入大盘相对强度评分调整 | 强势市场评分放大、弱势市场评分缩小 |

### 1.4 用户人群

| 用户 | 关注点 |
|------|--------|
| 策略使用者（个人投资者） | 在市场拐点（高位回落初期）不收到大量亏损信号，信号质量随市场状态自适应调整 |
| 策略维护者 | 可通过配置文件切换不同的市场状态识别方法（MACD/斜率/组合），便于 A/B 对比调优 |
| 回测验证者 | 4 个回测方案可独立运行、对比效果，回测报告能清晰展示各方案的差异 |

### 1.5 成功指标

V2.1 上线后，重新执行 `scripts/backtest_obpc.py` 回测，需满足以下任一方案的指标：

1. **方案一或方案三**（预期最优）：
   - 2026 年 1-3 月信号数 ≤ 10 个（原 34 个）；
   - 2026 年 1-3 月胜率 ≥ 45%；
   - 全区间胜率 ≥ 45%；
   - 全区间平均收益 ≥ 0%；
   - 硬止损笔数占比 ≤ 20%；
   - 全区间总信号数 ≥ 20 个。

2. **方案二或方案四**（备选）：
   - 2026 年 1-3 月信号数 ≤ 15 个；
   - 全区间胜率 ≥ 40%；
   - 全区间平均收益 ≥ -2%。

## 2. 用户需求

### 2.1 用户故事

**US-1：作为策略使用者，我希望策略能识别"大盘仍在均线上方但已开始下跌"的市场拐点，避免在下跌初期接到大量信号。**

> 验收要点：2026 年 1-3 月大盘高位回落期间，MACD DIF 转负或均线斜率转负时，信号产出数显著下降。

**US-2：作为策略使用者，我希望个股评分能反映大盘环境，强势市场的信号评分更高、弱势市场的信号评分更低，让我能优先关注强势市场的信号。**

> 验收要点：强势市场（大盘在 MA20 上方且 MA20 向上）个股评分 × 1.2；弱势市场（大盘在 MA20 下方或 MA20 向下）个股评分 × 0.8；大盘跌破 MA60 且 MA60 向下时评分归零。

**US-3：作为策略维护者，我希望能通过配置文件切换 4 种不同的市场状态识别方法，对比回测效果后选择最优方案上线。**

> 验收要点：4 个回测方案可通过配置文件独立启用，回测报告能清晰展示各方案的信号数、胜率、收益对比。

**US-4：作为策略维护者，我希望 MACD 参数、均线斜率阈值、评分调整系数都通过配置文件控制，无需修改代码即可调优。**

> 验收要点：所有 V2.1 新增参数均通过 `config/config.yaml` 配置，代码中无硬编码阈值。

**US-5：作为回测验证者，我希望回测脚本能完整模拟 V2.1 的市场状态识别逻辑，并输出各方案的对比报告。**

> 验收要点：`scripts/backtest_obpc.py` 支持通过命令行参数或配置切换 4 个回测方案，回测报告中包含市场状态识别命中的统计。

### 2.2 用户痛点分析

| 痛点 | V2.0 表现 | V2.1 期望表现 |

| 均线位置失效 | 60 日均线过滤命中 0 次，2026 年信号全部通过 | MACD 或斜率识别下跌拐点，命中 ≥ 50 次 |

### 3.2 功能详情

#### FR-1：MACD 动量过滤（第一步优化）

**需求描述**

用 MACD 的 DIF 线反映价格短期动量方向，替代当前"价格 vs 均线位置"的判断方式。当 DIF > 0 时视为多头区域（市场动量向上），允许开仓；当 DIF ≤ 0 时视为空头区域（市场动量向下），禁止开仓。

MACD 相比均线的优势在于：DIF 是短期均线（EMA12）与长期均线（EMA26）的差值，对价格拐点更灵敏。在 2026 年初的下跌中，DIF 会率先转负，能在指数仍位于 60 日均线上方时就关闭开仓信号。

**业务规则**

| 规则编号 | 规则描述 |
|---------|---------|
| BR-1.1 | MACD 过滤作为大盘趋势过滤的**可选替代方案**，通过 `index_filter.method` 配置项切换：`'ma_position'`（V2.0 原有，价格 vs 均线位置）或 `'macd'`（V2.1 新增，DIF 方向） |
| BR-1.2 | 当 `method: 'macd'` 时，计算大盘指数的 MACD 指标（DIF = EMA12 - EMA26，DEA = DIF 的 9 日 EMA），仅当 DIF > 0 时允许产生信号 |
| BR-1.3 | MACD 三个参数（fast=12, slow=26, signal=9）均可通过配置文件调整 |
| BR-1.4 | MACD 过滤条件可通过 `condition` 配置项自定义，目前支持 `'dif > 0'`，后续可扩展 `'dif > dea'`（金叉）等条件 |
| BR-1.5 | 当指数数据不足 `slow + signal`（默认 26 + 9 = 35）天时，跳过 MACD 过滤并输出警告日志，不阻断扫描 |
| BR-1.6 | MACD 过滤与 V2.0 的均线位置过滤互斥：`method` 只能取一个值，不能同时启用 |
| BR-1.7 | MACD 过滤命中时（DIF ≤ 0），输出日志"大盘 MACD 动量不足（DIF=X < 0），禁止开仓"，并计入风控命中统计 |

**配置参数**

```yaml
strategies:
  oversold_bounce:
    params:
      index_filter:
        enabled: true                    # 大盘过滤总开关（V2.0 原有）
        method: 'macd'                   # 过滤方法（V2.1 新增）：'ma_position' 或 'macd'
        index_code: "000300.SH"          # 指数代码（V2.0 原有）
        index_ma_period: 20              # 短周期均线（V2.0 原有，method='ma_position' 时生效）
        index_ma_period_long: 60         # 长周期均线（V2.0 原有，method='ma_position' 时生效）
        long_ma_filter_enabled: true     # 60日均线过滤开关（V2.0 原有，method='ma_position' 时生效）
        # MACD 参数（V2.1 新增，method='macd' 时生效）
        macd_fast: 12                    # 快线周期
        macd_slow: 26                    # 慢线周期
        macd_signal: 9                   # 信号线周期
        condition: 'dif > 0'             # 过滤条件
```

#### FR-2：均线斜率判断（第二步优化）

**需求描述**

即使大盘指数收盘价仍位于 60 日均线上方，如果 60 日均线斜率转负（均线向下拐头），视为弱势市场，禁止开仓。这一优化解决了"均线之上但仍在下跌"的识别问题。

均线斜率定义为：当前均线值相对于 N 天前均线值的变化率。当斜率大于阈值时视为向上，否则视为向下。

**业务规则**

| 规则编号 | 规则描述 |
|---------|---------|
| BR-2.1 | 均线斜率过滤作为大盘趋势过滤的**可选增强项**，通过 `slope_filter_enabled` 配置项独立开关 |
| BR-2.2 | 均线斜率计算公式：`slope = (ma.iloc[-1] - ma.iloc[-slope_lookback]) / ma.iloc[-slope_lookback]`，其中 `slope_lookback` 默认 5（即 5 天前的均线值） |
| BR-2.3 | 当 `slope > slope_threshold`（默认 0.002，即 0.2%）时视为均线向上，放行；否则视为均线向下，过滤 |
| BR-2.4 | 均线斜率过滤可应用于 MA20 或 MA60，通过 `slope_ma_period` 配置项指定（默认 60） |
| BR-2.5 | 均线斜率过滤可与 `method: 'ma_position'` 组合使用（价格在均线上方 + 均线斜率向上才放行），也可与 `method: 'macd'` 组合使用（双重确认） |
| BR-2.6 | 当指数数据不足 `slope_ma_period + slope_lookback` 天时，跳过斜率过滤并输出警告日志 |
| BR-2.7 | 均线斜率过滤命中时，输出日志"大盘均线斜率向下（slope=X < 阈值 Y），禁止开仓"，并计入风控命中统计 |

**配置参数**

```yaml
strategies:
  oversold_bounce:
    params:
      index_filter:
        # ... 其他参数同 FR-1 ...
        # 均线斜率过滤（V2.1 新增）
        slope_filter_enabled: false      # 斜率过滤开关（默认关闭，需手动启用）
        slope_ma_period: 60              # 计算斜率的均线周期（默认 60 日均线）
        slope_lookback: 5                # 斜率回看天数（当前均线 vs N 天前均线）
        slope_threshold: 0.002           # 斜率阈值（0.2%），大于该值才视为向上
```

#### FR-3：评分系统市场状态调整（第三步优化）

**需求描述**

在现有形态评分（跌幅深度/缩量程度/放量强度/回踩幅度/放量涨幅）的基础上，加入"大盘相对强度"作为加分/减分项，使个股评分能反映大盘环境的影响。

调整规则：
- 大盘在 MA20 上方且 MA20 向上（强势市场）：所有股票评分 × 1.2
- 大盘在 MA20 下方或 MA20 向下（弱势市场）：所有股票评分 × 0.8
- 大盘跌破 MA60 且 MA60 向下（极弱市场）：评分直接归零（禁止开仓）

**业务规则**

| 规则编号 | 规则描述 |
|---------|---------|
| BR-3.1 | 评分调整作为**可选增强项**，通过 `score_adjustment_enabled` 配置项独立开关 |
| BR-3.2 | 评分调整系数通过配置项控制：`strong_market_multiplier`（默认 1.2）、`weak_market_multiplier`（默认 0.8） |
| BR-3.3 | 强势市场判定：大盘收盘价 ≥ MA20 且 MA20 斜率 > 0（向上） |
| BR-3.4 | 弱势市场判定：大盘收盘价 < MA20 或 MA20 斜率 ≤ 0（向下） |
| BR-3.5 | 极弱市场判定：大盘收盘价 < MA60 且 MA60 斜率 ≤ 0（向下），此时评分直接归零 |
| BR-3.6 | 评分调整在个股形态评分计算完成后应用：`adjusted_score = original_score × multiplier`，调整后评分上限 100、下限 0 |
| BR-3.7 | 评分调整与 V2.0 的评分阈值过滤串联：调整后的评分用于阈值判断（弱势市场评分缩小后更容易被阈值过滤） |
| BR-3.8 | 极弱市场评分归零时，等同于被评分阈值过滤，输出日志"大盘极弱（跌破 MA60 且 MA60 向下），评分归零" |
| BR-3.9 | 评分调整命中时（系数 ≠ 1.0），日志中记录原始评分、调整系数、调整后评分，便于调试 |

**配置参数**

```yaml

  oversold_bounce:
    params:
      # 评分市场状态调整（V2.1 新增）
      score_adjustment:
        enabled: false                   # 评分调整开关（默认关闭）
        strong_market_multiplier: 1.2    # 强势市场评分放大系数
        weak_market_multiplier: 0.8      # 弱势市场评分缩小系数

        # 斜率判断复用 index_filter 的 slope_lookback 和 slope_threshold
```

## 4. 对 V2.0 风控系统的影响评估

### 4.1 影响概览

| V2.0 风控层 | V2.1 影响 | 影响程度 | 说明 |
|------------|----------|---------|------|
| 风控1：评分阈值过滤 | 新增评分调整前置处理 | 中 | 评分调整在阈值判断前应用，调整后的评分用于阈值判断 |
| 风控2：大盘趋势过滤 | 新增 MACD 和斜率两种过滤方法 | 高 | `method` 参数切换过滤方法，原有均线位置过滤保留 |
| 风控3：单月信号上限 | 无影响 | 无 | V2.1 不修改单月上限逻辑 |

### 4.2 详细影响分析

#### 4.2.1 对风控1（评分阈值过滤）的影响

**影响点**：V2.1 的评分调整（FR-3）在评分阈值判断前应用。

**变更说明**：
- V2.0 流程：`形态评分 → 评分阈值判断`
- V2.1 流程：`形态评分 → 评分调整（× 强弱系数）→ 评分阈值判断`

**兼容性**：
- 评分调整默认关闭（`score_adjustment.enabled: false`），关闭时流程与 V2.0 完全一致；
- 评分调整启用时，调整后的评分可能低于 V2.0 的原始评分，导致更多信号被阈值过滤（弱势市场评分 × 0.8）；
- 极弱市场评分归零，等同于被阈值过滤，不新增风控层级。

**风险**：
- 评分调整可能改变 V2.0 回测结果的基准线，需在回测对比时明确区分"仅评分调整"和"仅市场状态过滤"的效果；
- 建议 4 个回测方案默认关闭评分调整，单独评估市场状态识别的效果，评分调整作为独立增强项后续单独验证。

#### 4.2.2 对风控2（大盘趋势过滤）的影响

**影响点**：V2.1 的 MACD 过滤（FR-1）和斜率过滤（FR-2）替代或增强 V2.0 的均线位置过滤。

**变更说明**：
- V2.0 流程：`大盘收盘价 ≥ MA20 且 ≥ MA60 → 放行`
- V2.1 流程（method='macd'）：`大盘 DIF > 0 → 放行`（替代均线位置判断）
- V2.1 流程（method='ma_position' + slope_filter_enabled=true）：`大盘收盘价 ≥ MA20 且 MA20 斜率 > 阈值 → 放行`（增强均线位置判断）

**兼容性**：
- `method` 默认值建议为 `'ma_position'`，与 V2.0 行为一致；
- `slope_filter_enabled` 默认 `false`，关闭时与 V2.0 行为一致；
- MACD 过滤和均线位置过滤互斥（`method` 只能取一个值），不能同时启用。

**风险**：
- MACD 过滤可能过于灵敏，在震荡市频繁开关信号，需通过回测验证；
- 斜率阈值（0.2%）需要调优，过小则过滤效果弱，过大则可能漏掉有效信号；
- 4 个方案的对比需在相同的回测区间和股票池下进行，确保可比性。

#### 4.2.3 对风控3（单月信号上限）的影响

**影响点**：无。

**说明**：V2.1 不修改单月信号上限的逻辑，`max_signals_per_month` 继续按 V2.0 逻辑执行。V2.1 的市场状态过滤会减少信号产出，间接降低单月上限的命中率。

## 9. V2.1 回测验证结果

V2.1 优化代码通过代码检测、强制测试（4 方案回测）、代码审查（10 个问题已修复）后，针对 2025-01-01 ~ 2026-04-07 区间执行 4 个方案的回测验证。本章节记录实际回测数据、结论和改进建议，作为 V2.1 上线决策的依据。

### 9.1 回测环境

| 项目 | 说明 |
|------|------|
| 回测区间 | 2025-01-01 ~ 2026-04-07 |
| 回测年限 | 约 1.26 年 |
| 回测脚本 | `scripts/backtest_obpc.py` |
| 方案切换 | 通过 `--scheme 1/2/3/4` 命令行参数切换 |
| 基准对比 | V2.0 三层风控（均线位置 + 评分阈值 + 单月上限） |
| 区间特点 | 覆盖 2026 年初系统性下跌期，是 V2.0 风控失效的典型场景 |

### 9.2 4 方案回测数据

| 方案 | 过滤条件 | 总信号数 | 交易数 | 胜率 | 平均收益 | 累计收益 |
|------|---------|---------|--------|------|---------|---------|
| V2.0 基准 | 均线位置 + 评分阈值 + 单月上限 | - | 34 | 20.59% | -3.38% | - |
| 方案1 | MACD DIF > 0 | 117 | 34 | 23.53% | -3.38% | -114.84% |
| 方案2 | MA20 位置 + MA20 斜率 > 0 | 127 | 10 | 30.00% | -1.54% | -15.38% |
| 方案3 | MACD + MA20 斜率（双重确认） | 127 | 10 | 30.00% | -1.54% | -15.38% |
| 方案4 | MA60 斜率 > 0 | 121 | 24 | 16.67% | -5.31% | -127.35% |

### 9.3 回测结论

#### 9.3.1 方案效果对比

1. **方案2/3 表现最好**：
   - 胜率 30%，较 V2.0 基准（20.59%）提升 9.41 个百分点；
   - 平均收益 -1.54%，较 V2.0 基准（-3.38%）改善 1.84 个百分点；
   - 累计收益从 -114.84% 降至 -15.38%，亏损幅度显著降低；
   - 交易数从 34 笔降至 10 笔，过滤效果显著。

2. **方案2 与方案3 结果完全相同**：
   - 说明 MACD 过滤在 MA20 斜率过滤基础上无额外效果；
   - MA20 斜率过滤已足够识别 2026 年初的下跌拐点；
   - 推荐使用方案2（配置更简单，无需计算 MACD）。

3. **方案1 效果不明显**：
   - MACD DIF > 0 过滤未减少交易数（仍为 34 笔）；
   - 胜率仅小幅提升至 23.53%；
   - 说明单独使用 MACD 过滤不足以识别 2026 年初的下跌拐点，DIF 在指数仍位于均线上方时未及时转负。

4. **方案4 表现最差**：
   - MA60 斜率过滤的胜率（16.67%）甚至低于 V2.0 基准（20.59%）；
   - 累计收益 -127.35%，亏损幅度最大；
   - 说明 MA60 斜率滞后性较强，无法及时识别下跌拐点，反而可能错过反弹机会。

#### 9.3.2 整体结论

1. **所有方案在下跌市仍亏损**：符合"反转策略在下跌市天然胜率低"的诊断，V2.1 优化未能彻底解决下跌市亏损问题，但方案2/3 显著降低了亏损幅度。
2. **未达到预期 45% 胜率目标**：4 个方案均未达到本需求文档 1.3 节设定的 P0 目标"全区间胜率 ≥ 45%"，也未达到 6.2 节"方案一/三目标"的 45% 胜率要求。
3. **部分达到备选方案目标**：方案2/3 的胜率（30%）未达到备选方案"方案二/四目标"的 40% 胜率要求，但平均收益（-1.54%）优于备选方案的 -2% 要求，且将累计亏损从 -114.84% 降至 -15.38%，具有实际改善价值。
4. **V2.1 优化的核心价值**：在于通过 MA20 斜率过滤及时识别下跌拐点，减少下跌市的信号产出（从 34 笔降至 10 笔），从而降低累计亏损幅度，而非提升胜率至盈利水平。

### 9.4 与需求文档目标的差距分析

| 指标 | 方案一/三目标 | 方案二/四目标 | 方案2/3 实际 | 达标情况 |
|------|-------------|-------------|------------|---------|
| 2026 年 1-3 月信号数 | ≤ 10 | ≤ 15 | 10 | 达标（方案一/三目标） |
| 2026 年 1-3 月胜率 | ≥ 45% | ≥ 40% | 30% | 未达标 |
| 全区间胜率 | ≥ 45% | ≥ 40% | 30% | 未达标 |
| 全区间平均收益 | ≥ 0% | ≥ -2% | -1.54% | 达标（方案二/四目标） |
| 硬止损占比 | ≤ 20% | ≤ 25% | - | 待统计 |
| 全区间总信号数 | ≥ 20 | ≥ 20 | 10 | 未达标 |
| MACD/斜率过滤命中 | ≥ 50 次 | ≥ 30 次 | - | 待统计 |

**差距原因分析**：
1. 反转策略在下跌市天然胜率低，单纯通过市场状态识别过滤无法将胜率提升至 45%；
2. 2025-2026 区间以下跌市为主，缺乏 2020-2025 区间的上涨市样本，胜率统计偏低；
3. 信号数减少至 10 笔后，统计样本量较小，胜率波动较大。
