# 核心接口设计 V3

## 1. 概述

本文档定义 V3 系统的所有核心接口，基于实际代码的务实实现路线，包括：
- 策略层：BaseStrategy 抽象基类、Signal 数据结构、DataRequirement 数据结构
- 数据层：KlineService 接口、DatabaseManager 接口
- 回测层：BacktestEngine 接口、BacktestReport 接口
- 通知层：NotificationService 接口（单文件三合一实现）
- 引擎层：StrategyRegistry 接口、Scheduler 接口

接口设计原则：
- **务实优先**：接口直接对应实际代码，避免过度设计
- **依赖倒置**：高层模块依赖接口，不依赖具体实现
- **类型安全**：使用 Python typing 提供类型提示

## 2. 策略层接口

### 2.1 Signal 数据结构

定义于 [strategy/base.py](file:///Users/yl/vscode/stockfilter_v3/strategy/base.py)。

```python
from dataclasses import dataclass, field
from typing import Dict


@dataclass
class Signal:
    """
    策略信号
    策略 analyze 方法返回的信号对象
    """

    code: str
    """股票代码（不带后缀，如 600519）"""
    signal_type: str = 'buy'
    """信号类型：buy/sell/hold"""
    signal_date: str = ""
    """信号日期，格式 YYYY-MM-DD"""
    strategy_name: str = ""
    """策略名称"""
    strategy_version: str = ""
    """策略版本"""
    detail: Dict = field(default_factory=dict)
    """信号详情，包含支撑位、放量日期等（由策略自由填充）"""
    score: float = 0.0
    """信号评分（0-100），由策略 score() 方法计算"""
    backtest_params: Dict = field(default_factory=dict)
    """回测参数（由策略提供，供回测引擎使用）"""

    def to_dict(self) -> Dict:
        """将信号转为字典，方便序列化"""
        return {
            'code': self.code,
            'signal_type': self.signal_type,
            'signal_date': self.signal_date,
            'strategy_name': self.strategy_name,
            'strategy_version': self.strategy_version,
            'detail': self.detail,
            'score': self.score,
            'backtest_params': self.backtest_params,
        }
```

**关键设计说明**：
- `signal_date` 使用字符串格式（`YYYY-MM-DD`），而非 `date` 对象，方便序列化
- `detail` 字典承载策略特有的任意字段（支撑位、放量日期、回踩低点等），完全由策略自由填充
- `backtest_params` 由策略的 `get_backtest_params()` 方法提供，回测引擎从中读取止盈止损参数
- 无 `Frequency` 枚举：频率直接使用字符串 `'d'`, `'w'`, `'m'`
- 无 `SignalStatus` 枚举：信号状态由上层调度器管理

### 2.2 DataRequirement 数据结构

```python
@dataclass
class DataRequirement:
    """
    数据需求声明
    策略通过 declare_data_requirements 声明需要哪些数据
    由调度器/引擎统一获取后注入到 analyze 方法
    """
    code: str
    """股票代码（不带后缀，如 600519）"""
    frequency: str = 'd'
    """K 线频率：d=日线, w=周线, m=月线"""
    lookback: int = 120
    """回溯天数/条数"""
```

**关键设计说明**：
- `frequency` 是字符串，取值 `'d'`（日线）、`'w'`（周线）、`'m'`（月线），不使用枚举
- `code` 是策略声明自己需要哪些股票的数据，每个股票一个 DataRequirement
- 目前实际只使用日线（`'d'`），周线/月线在 klins 表中有对应字段支持但尚未在策略中使用

### 2.3 BaseStrategy 抽象基类

定义于 [strategy/base.py](file:///Users/yl/vscode/stockfilter_v3/strategy/base.py)。

```python
from abc import ABC, abstractmethod
from typing import Dict, List, Optional
import pandas as pd


class BaseStrategy(ABC):
    """
    策略基类
    所有策略必须继承此类并实现抽象方法。

    生命周期：
    1. 初始化 -> 加载 params
    2. declare_data_requirements -> 声明需要哪些股票的数据
    3. analyze(每个code) -> 逐只分析，返回 Signal 或 None
    4. score(可选) -> 对信号评分
    """

    # 子类必须设置的属性
    name: str = ""
    """策略名称，英文标识"""
    version: str = ""
    """策略版本"""
    description: str = ""
    """策略描述"""

    def __init__(self, params: Optional[Dict] = None):
        """
        初始化策略

        Args:
            params: 策略参数字典，覆盖默认参数
        """
        self.params = self._get_default_params()
        if params:
            self.params.update(params)

    @abstractmethod
    def _get_default_params(self) -> Dict:
        """
        获取策略默认参数
        子类实现，返回默认参数字典

        Returns:
            Dict: 默认参数
        """
        ...

    @abstractmethod
    def declare_data_requirements(self, codes: List[str]) -> List[DataRequirement]:
        """
        声明数据需求
        策略告诉引擎需要哪些股票的 K 线数据

        Args:
            codes: 股票代码列表

        Returns:
            List[DataRequirement]: 数据需求列表
        """
        ...

    @abstractmethod
    def analyze(self, code: str, data: Dict[str, pd.DataFrame]) -> Optional[Signal]:
        """
        分析单只股票，返回信号

        Args:
            code: 股票代码
            data: K 线数据字典，key 为频率标识（如 'd', 'w'），value 为 DataFrame

        Returns:
            Optional[Signal]: 如果产生信号则返回 Signal，否则返回 None
        """
        ...

    def score(self, signal: Signal) -> float:
        """
        对信号进行评分（可选重写）
        默认返回 0.0，子类可以重写实现自定义评分逻辑

        Args:
            signal: 信号对象

        Returns:
            float: 评分（0-100）
        """
        return 0.0

    def get_backtest_params(self) -> Dict:
        """
        获取回测参数（可选重写）
        返回策略特定的回测参数，供回测引擎使用

        Returns:
            Dict: 回测参数字典
        """
        return {}

    def __repr__(self) -> str:
        return f"{self.name}(v{self.version})"
```

**关键设计说明**（与旧版设计文档的差异）：
- 方法是 `analyze()` 而非 `detect()`，返回 `Optional[Signal]`（单个信号）而非 `List[Signal]`
- 数据需求方法是 `declare_data_requirements(codes)` 而非 `get_data_requirement()`，参数是股票列表
- 初始化用 `__init__(params)` + `_get_default_params()`，而非 `__init__(config)` + `_init_params()`
- `analyze` 的 `data` 参数是 `Dict[str, pd.DataFrame]`，key 是频率标识，支持多频率数据注入
- 当前实际场景中，调度器对每只股票调用一次 `analyze(code, {'d': df})`

**关键设计说明**：

- 单例模式，全局唯一实例通过 `get_registry()` 函数获取
- `register()` 接受**已实例化的策略对象**（而非策略类），由调用方负责实例化和参数注入
- 支持启用/禁用管理，调度器执行时只运行 `list_enabled()` 返回的策略
