# OBPC 策略说明文档

## 1. 策略概述

| 项目 | 说明 |
|------|------|
| 策略名称 | 超跌反弹后的回踩确认策略（Oversold Bounce Pullback Confirmation，OBPC） |
| 策略类型 | 右侧反转策略（波段交易） |
| 适用市场 | A股主板（沪市60xxxx、深市00xxxx） |
| 数据频率 | 日线（后复权） |
| 版本 | V2.1（代码版本 v25） |

OBPC 策略通过识别"大跌→缩量→放量启动→缩量走平→回踩确认"的五段式形态结构，捕捉超跌反弹后的低吸机会。策略属于右侧交易，等待放量启动信号出现后，在回踩支撑位时介入，以严格的风控条件控制下行风险。

## 2. 形态筛选参数（V2.0）

| 条件 | 参数值 | 说明 |
|------|--------|------|
| 前期大跌 | 跌幅 ≥ 12% | 滑动窗口20日内最高→最低 |
| 下跌末端缩量 | 存在成交量 ≤ 20日均量 × 0.6 | 放量日前10天内至少1天 |
| 放量启动日 | 涨幅 ≥ 5% | 收盘价相对前一日 |
| 放量量比 | 1.5 ~ 12 倍 | 相对前一交易日成交量 |
| 缩量走平 | 1 天 | 启动日后次日 |
| 走平缩量 | 成交量 ≤ 启动日 × 0.85 | 次日成交量 |
| 走平振幅 | ≤ 8% | (最高-最低)/收盘 |
| 回踩确认 | 最低价 ≥ 支撑位 × 0.985 | 允许轻微跌破1.5% |
| 支撑位定义 | 大跌区间最低点 | 前20日内最低价 |

## 3. 形态检测5步流程

### 3.1 大跌检测
滑动窗口20日内最高价到最低价跌幅 ≥ 12%。

### 3.2 缩量检测
放量日前10天内至少1天成交量 ≤ 20日均量 × 0.6。

### 3.3 放量检测
量比 1.5~12 倍且涨幅 ≥ 5%，次日缩量走平（量 ≤ 放量日 × 0.85，振幅 ≤ 8%）。

### 3.4 回踩确认
放量后10天内最低价 ≥ 支撑位 × 0.985（支撑位 = 大跌区间最低点）。

### 3.5 流动性检查
回踩日前20天日均成交额 ≥ 3000万。

## 4. 评分系统（5维度加权，0-100分）

| 维度 | 权重 | 评分规则 |
|------|------|---------|
| 跌幅深度 | 25% | 12%=60分，20%=100分 |
| 缩量程度 | 20% | 取实际缩量比例，0.6=60分，0.3=100分 |
| 放量强度 | 20% | 1.5倍=60分，3倍=100分 |
| 回踩幅度 | 20% | 未跌破支撑=100分，刚好满足=60分 |
| 放量涨幅 | 15% | 5%=60分，8%=100分 |

最终得分为各维度得分按权重加权求和，分数越高表示形态质量越好。

## 5. 风控过滤机制

### 5.1 基础风控

| 风控项 | 规则 | 说明 |
|--------|------|------|
| 流动性 | 日均成交额 ≥ 3000万 | 过去20天 |
| 信号间隔 | 同一股票 ≥ 60个交易日 | 避免短期重复信号 |
| 年度限制 | 每只股票 ≤ 2次/年 | 控制单票频次 |

### 5.2 三层风控增强（V2.0 风控增强）

策略在基础风控之上新增三层风控，按以下顺序串联执行，任一环节过滤即终止后续处理：

```
信号产出（策略层）
    ↓
[风控1] 动态评分阈值过滤（前置，避免低分信号占用单月名额）
    ↓ 通过
[风控2] 大盘趋势过滤（20日 + 60日均线）
    ↓ 通过
[风控3] 单月信号数量上限检查
    ↓ 通过
信号保存 + 推送
```

| 风控层 | 规则 | 配置参数 | 默认值 | 说明 |
|--------|------|---------|--------|------|
| 风控1：评分阈值 | 信号评分 < 当前生效阈值时过滤 | `score_filter.score_threshold` | 60（代码默认值） | 非弱势市场的基础阈值 |
| 风控1：评分阈值 | 弱势市场使用更高阈值 | `score_filter.score_threshold_weak` | 75 | 弱势市场（沪深300 < MA60）时生效 |
| 风控2：大盘趋势 | 沪深300 ≥ 20日均线 且 ≥ 60日均线 | `index_filter.index_ma_period` / `index_ma_period_long` | 20 / 60 | 任一不满足则过滤 |
| 风控2：大盘趋势 | 60日均线过滤可独立开关 | `index_filter.long_ma_filter_enabled` | true | 数据不足60天时跳过并警告 |
| 风控3：单月上限 | 当月信号数 ≥ 上限时过滤 | `max_signals_per_month` | 12 | 以信号日期所在自然月为统计单位 |

**执行顺序调整说明**：评分阈值前置，确保低分信号先被过滤，不会占用单月名额，避免高分信号因单月上限已满而被过滤（先到先得问题）。

**filter_rule 命名**：风控命中日志中，大盘趋势过滤统一记为 `long_ma_filter`，单月上限记为 `monthly_limit`，评分阈值记为 `score_threshold`。

> 风控增强的详细架构设计见 [OBPC风控增强架构设计.md](./OBPC风控增强架构设计.md)，需求规格见 [OBPC策略风控增强需求.md](./OBPC策略风控增强需求.md)。

### 5.3 V2.1 市场状态识别增强

V2.0 的"价格 vs 均线位置"判断方式存在滞后性问题：当指数从高位回落但尚未跌破 60 日均线时，均线过滤条件依然成立，导致 2026 年初系统性下跌期 60 日均线过滤命中 0 次，风控完全失效。V2.1 在 V2.0 三层风控基础上新增三种市场状态识别增强，可独立开关、互不影响。

#### 5.3.1 MACD 动量过滤（FR-1）

用 MACD 的 DIF 线反映价格短期动量方向，替代"价格 vs 均线位置"的判断方式。DIF 是短期均线（EMA12）与长期均线（EMA26）的差值，对价格拐点更灵敏，能在指数仍位于 60 日均线上方时就关闭开仓信号。

| 规则 | 说明 |
|------|------|
| 切换方式 | `index_filter.method: 'macd'`（与 `ma_position` 互斥） |
| 放行条件 | 大盘 DIF > 0（多头区域） |
| 过滤条件 | 大盘 DIF ≤ 0（空头区域），输出"大盘 MACD 动量不足"日志 |
| 数据不足处理 | 指数数据不足 `macd_slow + macd_signal`（默认 35 天）时跳过过滤并警告 |
| 命中统计 | 风控统计字段 `skipped_macd_filter` |

#### 5.3.2 均线斜率过滤（FR-2）

即使大盘指数收盘价仍位于均线上方，若均线本身已向下拐头（斜率转负），视为弱势市场，禁止开仓。这一优化解决了"均线之上但仍在下跌"的识别问题。

| 规则 | 说明 |
|------|------|
| 开关 | `index_filter.slope_filter_enabled: true` |
| 斜率公式 | `slope = (ma.iloc[-1] - ma.iloc[-slope_lookback]) / ma.iloc[-slope_lookback]` |
| 放行条件 | `slope > slope_threshold`（默认 0.002，即 0.2%） |
| 过滤条件 | `slope ≤ slope_threshold`，输出"大盘均线斜率向下"日志 |
| 适用均线 | MA20 或 MA60，通过 `slope_ma_period` 指定（默认 60） |
| 组合使用 | 可与 `ma_position` 或 `macd` 组合，实现双重确认 |
| 数据不足处理 | 指数数据不足 `slope_ma_period + slope_lookback` 天时跳过并警告 |
| 命中统计 | 风控统计字段 `skipped_slope_filter` |

#### 5.3.3 评分市场状态调整（FR-3）

在个股形态评分基础上加入"大盘相对强度"作为加分/减分项，使个股评分能反映大盘环境的影响。评分调整在评分阈值判断前应用，调整后的评分用于阈值判断。

| 市场状态 | 判定条件 | 调整系数 | 默认值 |
|---------|---------|---------|--------|
| 强势市场 | 大盘收盘价 ≥ MA20 且 MA20 斜率 > 0 | `score_multiplier_strong` | × 1.2 |
| 弱势市场 | 大盘收盘价 < MA20 或 MA20 斜率 ≤ 0 | `score_multiplier_weak` | × 0.8 |
| 极弱市场 | 大盘收盘价 < MA60 且 MA60 斜率 ≤ 0 | `score_multiplier_extreme_weak` | × 0.0（归零） |

| 规则 | 说明 |
|------|------|
| 开关 | `score_adjustment.enabled: true`（默认关闭） |
| 调整公式 | `adjusted_score = original_score × multiplier` |
| 评分上下限 | 上限 `score_max_limit`（默认 100.0），下限 `score_min_limit`（默认 0.0） |
| 极弱市场 | 评分直接归零，等同于被评分阈值过滤，输出"大盘极弱，评分归零"日志 |
| 日志记录 | 系数 ≠ 1.0 时记录原始评分、调整系数、调整后评分 |
| 命中统计 | 风控统计字段 `skipped_score_adjustment` |

#### 5.3.4 V2.1 与 V2.0 风控的关系

| V2.0 风控层 | V2.1 影响 | 关系 |
|------------|----------|------|
| 风控1：评分阈值过滤 | 评分调整作为前置处理 | 调整后评分用于阈值判断 |
| 风控2：大盘趋势过滤 | MACD/斜率作为替代或增强 | `method` 切换过滤方法，斜率可叠加 |
| 风控3：单月信号上限 | 无影响 | 继续按 V2.0 逻辑执行 |

**兼容性**：V2.1 所有新增功能默认关闭，启用 V2.0 配置时行为与 V2.0 完全一致。各功能可独立开关，互不影响。

> V2.1 优化的详细需求规格见 [OBPC策略V2.1优化需求.md](./OBPC策略V2.1优化需求.md)。

## 11. V2.1 回测验证结果（2025-01-01 ~ 2026-04-07）

V2.1 优化完成后，针对 2025-01-01 ~ 2026-04-07 区间执行 4 个方案的回测验证，对比 V2.0 基准评估各方案效果。本区间覆盖 2026 年初系统性下跌期，是 V2.0 风控失效的典型场景。

### 11.1 4 方案回测对比

| 方案 | 过滤条件 | 总信号数 | 交易数 | 胜率 | 平均收益 | 累计收益 |
|------|---------|---------|--------|------|---------|---------|
| V2.0 基准 | 均线位置 + 评分阈值 + 单月上限 | - | 34 | 20.59% | -3.38% | - |
| 方案1 | MACD DIF > 0 | 117 | 34 | 23.53% | -3.38% | -114.84% |
| 方案2 | MA20 位置 + MA20 斜率 > 0 | 127 | 10 | 30.00% | -1.54% | -15.38% |
| 方案3 | MACD + MA20 斜率（双重确认） | 127 | 10 | 30.00% | -1.54% | -15.38% |
| 方案4 | MA60 斜率 > 0 | 121 | 24 | 16.67% | -5.31% | -127.35% |

### 11.2 回测结论

1. **方案2/3 表现最好**：胜率 30%（较 V2.0 基准 20.59% 提升 9.41pp），平均收益 -1.54%（较 V2.0 基准 -3.38% 改善 1.84pp），累计收益从 -114.84% 降至 -15.38%。
2. **方案2 与方案3 结果相同**：说明 MACD 过滤在 MA20 斜率过滤基础上无额外效果，MA20 斜率过滤已足够识别下跌拐点。
3. **方案1 效果不明显**：MACD DIF > 0 过滤未减少交易数（仍为 34 笔），胜率仅小幅提升至 23.53%，说明单独使用 MACD 过滤不足以识别 2026 年初的下跌拐点。
4. **方案4 表现最差**：MA60 斜率过滤的胜率（16.67%）甚至低于 V2.0 基准，累计收益 -127.35%，说明 MA60 斜率滞后性较强，无法及时识别下跌拐点。
5. **所有方案在下跌市仍亏损**：符合"反转策略在下跌市天然胜率低"的诊断，V2.1 优化未能彻底解决下跌市亏损问题，但方案2/3 显著降低了亏损幅度。
6. **未达到预期 45% 胜率目标**：4 个方案均未达到 V2.1 需求文档中设定的 45% 胜率目标，但方案2/3 达到了备选方案"胜率 ≥ 40%"的部分缓解目标（实际 30%），且将亏损从 -114.84% 降至 -15.38%。

### 11.3 V2.1 使用建议

| 建议 | 说明 |
|------|------|
| 推荐方案 | **方案2**（MA20 位置 + MA20 斜率 > 0），效果与方案3 相同但配置更简单 |
| 下跌市谨慎操作 | 即使启用 V2.1 过滤，下跌市仍可能亏损，建议结合大盘环境手动控制仓位或暂停操作 |
| 评分调整按需启用 | 评分调整（FR-3）作为独立增强项，可根据需要单独启用，4 个回测方案默认关闭 |
| 参数调优 | 斜率阈值（0.2%）和 MACD 参数（12/26/9）可通过配置文件调整，回测后选择最优值 |
| 持续监控 | 上线后持续监控各过滤规则的命中次数和信号质量，定期评估是否需要调整参数 |

## 12. V2.1 配置参数说明

V2.1 新增配置参数全部位于 `config/config.yaml` 的 `strategies.oversold_bounce.params` 节下，所有参数均有默认值，确保 V2.0 配置文件可正常运行。

### 12.1 index_filter 区块（V2.1 新增参数）

| 参数 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|--------|---------|------|
| `method` | str | `'ma_position'` | `'ma_position'` / `'macd'` | 大盘趋势过滤方法，`ma_position` 为 V2.0 均线位置过滤，`macd` 为 V2.1 动量过滤 |
| `macd_fast` | int | 12 | 正整数 | MACD 快线周期（EMA12），`method: 'macd'` 时生效 |
| `macd_slow` | int | 26 | 正整数 | MACD 慢线周期（EMA26），`method: 'macd'` 时生效 |
| `macd_signal` | int | 9 | 正整数 | MACD 信号线周期（DIF 的 9 日 EMA），`method: 'macd'` 时生效 |
| `condition` | str | `'dif > 0'` | `'dif > 0'` | MACD 过滤条件，目前支持 `dif > 0`，后续可扩展 `dif > dea`（金叉） |
| `slope_filter_enabled` | bool | false | true / false | 均线斜率过滤开关，默认关闭 |
| `slope_ma_period` | int | 60 | 20 / 60 | 斜率计算的均线周期，可选 MA20 或 MA60 |
| `slope_lookback` | int | 5 | 正整数 | 斜率回看天数（当前均线 vs N 天前均线） |
| `slope_threshold` | float | 0.002 | 正浮点数 | 斜率阈值（0.2%），大于该值才视为均线向上 |
| `min_index_data_days` | int | 30 | 正整数 | 最小指数数据获取天数，数据不足时跳过过滤并警告 |

### 12.2 score_adjustment 区块（V2.1 新增参数）

| 参数 | 类型 | 默认值 | 取值范围 | 说明 |
|------|------|--------|---------|------|
| `enabled` | bool | false | true / false | 评分市场状态调整开关，默认关闭 |
| `score_multiplier_strong` | float | 1.2 | 正浮点数 | 强势市场评分放大系数 |
| `score_multiplier_weak` | float | 0.8 | 正浮点数 | 弱势市场评分缩小系数 |
| `score_multiplier_extreme_weak` | float | 0.0 | 非负浮点数 | 极弱市场评分系数，0 = 评分归零 |
| `score_max_limit` | float | 100.0 | 正浮点数 | 评分调整后上限 |
| `score_min_limit` | float | 0.0 | 非负浮点数 | 评分调整后下限 |
