# 伊利股份独立波段策略

版本：V1.0；最后更新：2026-11-06。

## 规则与数据

- 策略模块：`strategy/yili_swing/strategy.py`；标的与 RSI、均线、止损阈值统一读取 `config/config.yaml` 的 `strategies.yili_swing.params`。
- 只接受明确标记为前复权的伊利股份日线。原始生产 `klines` 不带复权标识，不能直接送进策略。RSI 用 Wilder 平滑；MA 使用收盘价简单均线。
- MA20 > MA60 且 RSI(10) 从上向下穿过 30 时产生买入收盘信号；RSI(10) 从下向上穿过 70 时产生卖出收盘信号。指标信号在下一交易日开盘执行；持仓期间盘中低价触及买入成交价下方 8% 时模拟止损。
- 信号函数只返回当天原始买卖条件。独立运行入口用历史日线重放模拟仓位，只有空仓买入、持仓卖出才列为 `next_open_action`。`model_position` 是策略模拟状态，不是券商账户持仓；日线止损为事后模拟，不提供盘中执行能力。

## 单次运行

将已核实的前复权 CSV 放到本机，例如 `data/backtest/yili_front.csv`，然后执行：

```bash
python3 scripts/run_yili_swing.py \
  --data data/backtest/yili_front.csv \
  --adjustment front \
  --expected-date 2026-11-05
```

`--expected-date` 必须填写预期最新交易日；数据未更新到该日期时程序报错，避免复用旧信号。入口输出 JSON，不下单、不推送。历史重放和参数评估都在本机进行；生产服务器只做数据筛选或导出，不能运行回测。

研究脚本 `scripts/backtest_swing.py` 与独立策略共用 RSI、均线和收盘信号函数；回测交易成本仍由 `section_backtest.swing` 配置。研究脚本默认期末强制平仓，用于计算完整样本绩效；独立运行入口不强平期末持仓，用于展示最新模拟状态。

## 每日生产扫描与通知

`strategy-yili` 容器复用 OBPC 镜像的依赖，但运行独立的 `scripts/scheduler_yili.py`。北京时间 08:20 至 09:10 触发及重试；只有交易日历可信且当天为交易日时，才处理**前一已收盘交易日**。调度时间、重试间隔、行情起点和已推送状态路径来自 `strategies.yili_swing.daily`。每日任务 `scripts/daily_yili_swing.py` 只通过 Baostock `adjustflag=2` 获取前复权日线并筛选目标日收盘指标，不调用回测或参数优化。数据最后日期不等于目标日期、复权查询失败或通知失败时不写已推送状态，并在截止时间前按配置间隔重试。

成功通知后，日期写入持久化的 `signals/yili_swing/push_state.json`；同一日期重启后不会重复通知。通知包含买、卖或无信号的每日摘要，均为**原始收盘条件**，不表示实盘仓位或可执行指令。当前每日任务不跟踪盘中止损；实盘风险处理需要独立的盘中行情与账户持仓来源。Webhook 已发出但在写状态前进程中断时，重试可能重复发送。

无需飞书的本地核查可运行 `python3 scripts/daily_yili_swing.py --date YYYY-MM-DD --dry-run`；该命令仍需本机 Baostock 可用，且不会写已推送状态。生产调度使用 `--run-date` 解析前一个已收盘交易日。生产编排和发布门槛已写入仓库，但本次未发布服务器。
