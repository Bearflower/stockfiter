# 股票筛选项目任务归档工作流

完整读取 `.trae/rules/task-management.md`，并检查仓库已有的任务记录与 `docs/` 下相关计划。旧规则中的 `task.md`、`.trae/memories` 和 Trae 会话对象仅表示任务登记与过程持久化职责；优先使用仓库已有结构，不得伪造工具调用或无依据创建并行系统。

1. 确认任务的验收条件和实际完成状态。验证未通过或仍有必需工作时，保持进行中或受阻状态。
2. 查找已有任务登记；只有用户要求持久化时才新增最小记录，并采用仓库既有格式。
3. 记录完成时间、目标、主要决策、改动文件、验证命令与结果、遗留问题和后续建议。
4. 检查行为、配置、API、部署或操作方式变化是否需要更新 `docs/`；无影响时明确记录。
5. 只有仓库已采用 `.trae/memorics` 或用户明确要求该格式时，才向其中写入过程记录；不要自动提交、推送、部署或删除工作文件。
