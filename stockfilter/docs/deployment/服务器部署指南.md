**这是部署的前提条件！**

#### 步骤 1: 生成 SSH 密钥

```bash
# 生成 ED25519 密钥（推荐）
ssh-keygen -t ed25519 -C "your_email@example.com"
```

**提示**: 直接回车，**不需要设置密码短语**

#### 步骤 2: 复制公钥到服务器

```bash
# 方法 1：使用 ssh-copy-id（推荐）
ssh-copy-id -i /Users/yl/vscode/inspection_automation/docs/only.pem.pub -o StrictHostKeyChecking=no root@43.156.242.184

# 方法 2：手动复制
cat /Users/yl/vscode/inspection_automation/docs/only.pem.pub | ssh -o StrictHostKeyChecking=no root@43.156.242.184 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
```

#### 步骤 3: 测试免密登录

```bash
ssh -o StrictHostKeyChecking=no root@43.156.242.184 "echo 成功"
```

**如果不需要输入密码就返回"成功"，说明配置成功！**

## ⏰ 定时任务配置

### 主程序定时任务（推荐）

项目使用统一主程序 `main.py` 管理定时任务:

**定时任务时间表**:
- **14:00 UTC (22:00 北京)** - K线数据更新
- **14:10 UTC (22:10 北京)** - 形态扫描
- **00:10 UTC (08:10 北京)** - 飞书推送
- **02:00 UTC (10:00 北京)** - 历史数据补全

**启动定时任务**:
```bash
# 容器启动后自动运行定时任务模式
python main.py

# 或显式指定
python main.py --schedule
```

### Docker 容器内定时任务

容器已配置定时任务，使用主程序 `main.py`:
- **执行时间**: 每天 22:10（北京时间）
- **执行内容**: `main.py --scan`（形态扫描）
- **推送时间**: 每天 08:10（北京时间）
- **执行内容**: `main.py --push`（飞书推送）

**注意**: 定时任务在容器启动后自动运行，无需额外配置 crontab。

## 🔍 故障排查

### 问题 1: SSH 无法免密登录

**症状**: 仍然提示输入密码

**解决方案**:
```bash
# 检查 /root 目录权限
ssh root@43.156.242.184 "ls -ld /root"
# 应该显示：drwx------ 27 root root ... /root

# 如果权限不正确，修复它
ssh root@43.156.242.184 "chown root:root /root && chmod 700 /root"

# 重新配置 SSH 密钥
ssh-copy-id -i /Users/yl/vscode/inspection_automation/docs/only.pem.pub root@43.156.242.184
```

### 问题 2: Docker 容器无法启动

**症状**: 容器启动后立即退出

**解决方案**:
```bash
# 查看详细错误
ssh root@43.156.242.184 "docker logs stockfilter-app --tail 100"

# 检查配置文件
ssh root@43.156.242.184 "cat /root/stockfilter/.env"

# 手动启动调试
ssh root@43.156.242.184 "docker-compose -f /root/stockfilter/docker-compose.yml up"
```

### 问题 3: 飞书推送失败

**症状**: 推送脚本报错或收不到消息

**解决方案**:
```bash
# 检查 webhook 配置
ssh root@43.156.242.184 "grep FEISHU_WEBHOOK /root/stockfilter/feishu_push.py"

# 应该显示：FEISHU_WEBHOOK = "https://open.feishu.cn/open-apis/bot/v2/hook/955aced6-5b07-42a6-a714-4c5f4726b003"

# 如果不对，手动修改
ssh root@43.156.242.184 "sed -i 's|YOUR_WEBHOOK_URL|https://open.feishu.cn/open-apis/bot/v2/hook/955aced6-5b07-42a6-a714-4c5f4726b003|g' /root/stockfilter/feishu_push.py"
```

### 问题 4: 数据库连接失败

**症状**: 无法连接 PostgreSQL 数据库

**解决方案**:
```bash
# 检查数据库容器
ssh root@43.156.242.184 "docker ps -f name=postgres"

# 测试数据库连接
ssh root@43.156.242.184 "docker exec stockfilter-app python3 -c \"from data.database import DatabaseManager; db = DatabaseManager(); print('数据库连接成功')\""

# 如果数据库未运行，重启它
ssh root@43.156.242.184 "docker restart postgres"
```
