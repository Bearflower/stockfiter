## 📝 技术说明

### V2.1 回测器

**文件**: `backtester_scheme_ab.py`

**特性**:
- ✅ 方案 A+B 逻辑（放宽参数 + 取消缩量走平）
- ✅ 流动性过滤（V2.1 新增）
- ✅ 大盘过滤（可选）
- ✅ 高开过滤（涨停/高开>5% 跳过）
- ✅ 交易成本扣除（0.35%）

### V2.1 配置文件

**文件**: `config_v21.yaml`

**关键参数**:
```yaml
pattern:
  drop_threshold: 0.12          # 跌幅 12%
  limit_up_threshold: 0.05      # 放量涨幅 5%
  min_volume_ratio: 1.5         # 量比 1.5 倍
  max_volume_ratio: 12.0        # 量比 12 倍
  flat_days: 0                  # 取消缩量走平
  
trading:
  enable_market_filter: true    # 大盘过滤
  min_avg_volume: 30000000      # 流动性过滤
  commission: 0.00025           # 交易成本
```
