### 3️⃣ 量能绝对额过滤

#### 问题
当前策略可能选中日均成交额过小的股票（如<3000 万），存在流动性风险。

#### 建议方案
```yaml
stock_pool:
  min_avg_volume: 30000000    # 日均成交额>=3000 万
  volume_check_period: 20     # 统计 20 日均值
```

#### 实现逻辑
在回测前过滤股票池：
```python
def check_liquidity(df, min_avg_volume=30000000):
    """检查流动性"""
    # 计算 20 日平均成交额
    df['amount_ma20'] = df['amount'].rolling(20).mean()
    
    # 检查启动日前流动性
    avg_amount = df['amount_ma20'].iloc[-20:].mean()
    
    return avg_amount >= min_avg_volume
```

#### 预期影响
- **可能减少信号数量**: 约 10-20%（排除小盘股）
- **提高流动性**: 避免无法及时买卖的风险
- **可能提高胜率**: 大盘股走势更稳定
