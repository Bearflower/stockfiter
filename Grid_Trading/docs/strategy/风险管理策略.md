## 1. 概述

### 1.1 风险管理目标

风险管理模块是网格交易系统的安全防线，负责：
- 在市场出现极端行情时保护资金安全
- 在盈利达到目标后锁定利润，避免利润回吐
- 在系统异常时及时止损，防止损失扩大
- 根据波动率动态调整仓位，实现风险均衡

### 1.2 风险管理架构

```
┌─────────────────────────────────────────────────┐
│               风险管理体系                        │
├─────────────────────────────────────────────────┤
│                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │ 硬止损   │  │ 移动止盈 │  │ 紧急暂停协议 │  │
│  │ 保护本金 │  │ 锁定利润 │  │ 系统异常处理 │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
│                                                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────────┐  │
│  │ 滑点保护 │  │ 动态仓位 │  │ 仓位可行性   │  │
│  │ 减少损耗 │  │ 风险均衡 │  │ 最小张数验证 │  │
│  └──────────┘  └──────────┘  └──────────────┘  │
│                                                 │
└─────────────────────────────────────────────────┘
```

### 1.3 风险级别分类

| 级别 | 场景 | 响应动作 |
|------|------|---------|
| **低风险** | 正常波动，价格在网格范围内 | 继续运行，无需干预 |
| **中风险** | 价格接近网格边界，或波动率上升 | 推送提醒，准备调整参数 |
| **高风险** | 价格突破边界，触发止盈止损 | 终止网格，平仓离场 |
| **极高风险** | 系统异常，网络断开，强趋势 | 紧急暂停，强制空仓 |

## 2. 硬止损机制

### 2.1 监控对象

硬止损监控的是**策略总盈亏**，包括：
- **已实现盈亏**：已平仓的网格交易累计盈亏
- **未实现盈亏**：当前持仓的浮动盈亏

```
总盈亏 = 已实现盈亏 + 未实现盈亏
总盈亏百分比 = 总盈亏 / 初始保证金 × 100%
```

### 2.2 触发条件

| 条件 | 阈值 | 说明 |
|------|------|------|
| 总亏损比例 | ≥ 初始保证金的 8% | 强制止损 |

### 2.3 执行动作

当总亏损达到 8% 时，执行以下动作：

```
1. 立即终止网格
2. 市价平仓所有持仓（带滑点保护）
3. 发送警报通知（飞书推送）
4. 记录止损事件日志
5. 暂停后续巡检，等待用户确认
```

### 2.4 Python 实现

```python
class HardStopLoss:
    """硬止损管理器"""
    
    def __init__(self, initial_margin, stop_loss_ratio=0.08):
        """
        参数:
            initial_margin: 初始保证金
            stop_loss_ratio: 止损比例（默认8%）
        """
        self.initial_margin = initial_margin
        self.stop_loss_ratio = stop_loss_ratio
        self.max_loss = initial_margin * stop_loss_ratio
        self.is_triggered = False
    
    def check(self, realized_pnl, unrealized_pnl):
        """
        检查是否触发止损
        
        参数:
            realized_pnl: 已实现盈亏
            unrealized_pnl: 未实现盈亏
        
        返回:
            bool: 是否触发止损
        """
        if self.is_triggered:
            return True
        
        total_pnl = realized_pnl + unrealized_pnl
        
        if total_pnl <= -self.max_loss:
            self.is_triggered = True
            return True
        
        return False
    
    def get_status(self, realized_pnl, unrealized_pnl):
        """
        获取当前状态
        
        返回:
            {
                "total_pnl": 总盈亏,
                "pnl_percent": 盈亏百分比,
                "max_loss": 最大亏损额度,
                "is_triggered": 是否触发,
                "distance_to_stop": 距离止损的额度
            }
        """
        total_pnl = realized_pnl + unrealized_pnl
        pnl_percent = total_pnl / self.initial_margin
        
        return {
            "total_pnl": total_pnl,
            "pnl_percent": pnl_percent,
            "max_loss": self.max_loss,
            "is_triggered": total_pnl <= -self.max_loss,
            "distance_to_stop": total_pnl + self.max_loss
        }
```

### 2.5 与网格终止价格的关系

硬止损是**最后防线**，与网格终止价格（止损线）的区别：

| 维度 | 网格终止价格 | 硬止损 |
|------|------------|--------|
| 触发依据 | 价格突破边界 | 总资金亏损比例 |
| 作用时机 | 价格触及止损线 | 累计亏损达到阈值 |
| 优先级 | 第一道防线 | 最后防线 |
| 适用场景 | 正常行情 | 极端行情或判断错误 |

## 3. 移动止盈机制

### 3.1 核心思想

当网格总利润达到目标后，系统不再等待价格跌回成本线才止损，而是将止盈价"绑定"在价格峰值上。只要价格从最高点回撤一定幅度，就立刻宣告这轮趋势结束，锁定大部分利润。

### 3.2 触发条件与参数

| 参数 | 设定值 | 说明 |
|------|--------|------|
| 盈利启动线 | +15% | 网格总盈利达到投入保证金的15%时启动 |
| 追踪回撤比例 | 5% | 从历史最高价回撤5%即触发止盈 |
| 追踪对象 | 标记价格（Mark Price） | 使用币安标记价格，避免成交价波动误触发 |

### 3.3 工作原理

#### 阶段一：震荡期（未启动移动止盈）

- **市场状态**：震荡市（ADX < 20）或降级震荡
- **收益来源**：网格震荡套利
- **退出方式**：系统推送的"终止最低价/最高价"，价格突破后手动终止网格

#### 阶段二：趋势期（移动止盈发挥作用）

当市场状态变为上升趋势或下降趋势时：

```
1. 信号灯推送新网格参数（非对称网格，启用上移/下移功能）
2. 用户根据推送创建新网格
3. 持续监控总盈亏：
   
   a. 若盈利从未达到15%，但价格先触碰了终止止损价
      → 网格终止，代表趋势判断错误，止损离场
   
   b. 若盈利达到15%
      → 系统计算新的"终止最高价/最低价"并推送
      → 用户手动更新止盈价格
```

### 3.4 计算公式

#### 上升趋势中的移动止盈

```
peak_price = 自网格启动以来的最高标记价格
新终止最高价 = min(当前终止最高价, peak_price × (1 - 0.05))
```

#### 下降趋势中的移动止盈

```
peak_price = 自网格启动以来的最低标记价格
新终止最低价 = max(当前终止最低价, peak_price × (1 + 0.05))
```

### 3.5 完整运行逻辑

```python
class TrailingTakeProfit:
    """移动止盈管理器"""
    
    def __init__(self, initial_margin, trigger_ratio=0.15, 
                 trail_ratio=0.05):
        """
        参数:
            initial_margin: 初始保证金
            trigger_ratio: 盈利启动线（默认15%）
            trail_ratio: 追踪回撤比例（默认5%）
        """
        self.initial_margin = initial_margin
        self.trigger_ratio = trigger_ratio
        self.trail_ratio = trail_ratio
        self.is_active = False
        self.peak_price = None
        self.profit_target = initial_margin * trigger_ratio
    
    def update(self, current_price, total_pnl, market_state):
        """
        更新移动止盈状态
        
        参数:
            current_price: 当前标记价格
            total_pnl: 总盈亏
            market_state: 市场状态
        
        返回:
            {
                "is_triggered": 是否触发止盈,
                "new_stop_price": 新止盈价格（若需要更新）,
                "is_active": 是否已激活
            }
        """
        result = {
            "is_triggered": False,
            "new_stop_price": None,
            "is_active": self.is_active
        }
        
        # 检查是否达到启动线
        if not self.is_active and total_pnl >= self.profit_target:
            self.is_active = True
            self.peak_price = current_price
            result["is_active"] = True
        
        # 如果已激活，追踪峰值
        if self.is_active:
            if market_state == "上升趋势":
                # 更新最高价
                if self.peak_price is None or current_price > self.peak_price:
                    self.peak_price = current_price
                
                # 计算追踪止盈价
                trail_stop_price = self.peak_price * (1 - self.trail_ratio)
                
                # 检查是否触发
                if current_price <= trail_stop_price:
                    result["is_triggered"] = True
                    result["new_stop_price"] = trail_stop_price
                else:
                    # 返回建议的新止盈价格
                    result["new_stop_price"] = trail_stop_price
            
            elif market_state == "下降趋势":
                # 更新最低价
                if self.peak_price is None or current_price < self.peak_price:
                    self.peak_price = current_price
                
                # 计算追踪止盈价
                trail_stop_price = self.peak_price * (1 + self.trail_ratio)
                
                # 检查是否触发
                if current_price >= trail_stop_price:
                    result["is_triggered"] = True
                    result["new_stop_price"] = trail_stop_price
                else:
                    result["new_stop_price"] = trail_stop_price
        
        return result
```

### 3.6 运行示例

**上升趋势示例**：

| 步骤 | 事件 | peak_price | 当前价格 | 追踪止盈价 | 动作 |
|------|------|-----------|---------|-----------|------|
| 1 | 网格启动 | - | 68000 | - | 初始终止最高价=78000 |
| 2 | 价格上涨 | 68000 | 70000 | 64600 | 未激活（盈利<15%） |
| 3 | 盈利达到15% | 72000 | 72000 | 68400 | 激活移动止盈 |
| 4 | 价格继续上涨 | 76500 | 76500 | 72675 | 推送新终止最高价 |
| 5 | 用户手动更新 | 76500 | 76500 | 72675 | 终止最高价改为72675 |
| 6 | 价格创新高 | 77000 | 77000 | 73150 | 更新峰值 |
| 7 | 价格回落 | 77000 | 73000 | 73150 | 跌破73150，触发止盈 |

### 3.7 半自动模式下的手动操作

由于目前是半自动系统，移动止盈需要用户手动完成：

```
当收到"移动止盈已启动"推送时：
1. 打开币安APP，找到正在运行的网格
2. 终止当前网格
3. 用完全相同的网格数量、价格区间、上移/下移价格
4. 填入新的"终止止损价"，重新创建网格
```

**注意**：这是强制要求手动干预的步骤，也是将来最需要养成习惯、转化为肌肉记忆的动作。

## 4. 紧急暂停协议

### 4.1 触发条件

满足以下**任意一条**即触发紧急暂停：

| 条件 | 说明 | 严重程度 |
|------|------|---------|
| 价格连续突破多层网格 | 5分钟内突破3层以上 | 高 |
| API连续报错 | 连续3次API调用失败 | 高 |
| API延迟过大 | 响应延迟 > 3秒 | 中 |
| 网络断开 | 无法连接到币安服务器 | 高 |

### 4.2 执行动作

紧急暂停触发后，按以下顺序执行：

```
第1步：取消所有挂单（暂停新订单）
        → 防止在异常情况下继续开仓

第2步：保持现有持仓，不平仓（"就地卧倒"）
        → 避免在系统异常时市价平仓造成更大损失

第3步：发送警报通知
        → 通过飞书/钉钉/Telegram推送紧急警报

第4步：尝试恢复
        → 持续检测系统状态，等待恢复正常

第5步：恢复后重新计算参数
        → 系统稳定后，重新评估市场状态和网格参数
```

### 4.3 Python 实现

```python
class EmergencyPause:
    """紧急暂停协议"""
    
    def __init__(self, max_api_errors=3, max_api_delay=3.0,
                 max_grid_breakthrough=3, breakthrough_window=300):
        """
        参数:
            max_api_errors: 最大API错误次数
            max_api_delay: 最大API延迟（秒）
            max_grid_breakthrough: 最大网格突破层数
            breakthrough_window: 突破时间窗口（秒，默认300=5分钟）
        """
        self.max_api_errors = max_api_errors
        self.max_api_delay = max_api_delay
        self.max_grid_breakthrough = max_grid_breakthrough
        self.breakthrough_window = breakthrough_window
        
        self.is_paused = False
        self.api_error_count = 0
        self.grid_breakthroughs = []
        self.pause_reason = None
    
    def record_api_error(self):
        """记录API错误"""
        self.api_error_count += 1
        if self.api_error_count >= self.max_api_errors:
            self._trigger("API连续报错")
    
    def record_api_delay(self, delay_seconds):
        """记录API延迟"""
        if delay_seconds > self.max_api_delay:
            self._trigger(f"API延迟过大: {delay_seconds:.1f}秒")
    
    def record_grid_breakthrough(self, timestamp):
        """记录网格突破"""
        import time
        current_time = timestamp or time.time()
        
        # 清理过期记录
        cutoff = current_time - self.breakthrough_window
        self.grid_breakthroughs = [
            t for t in self.grid_breakthroughs if t > cutoff
        ]
        
        self.grid_breakthroughs.append(current_time)
        
        if len(self.grid_breakthroughs) >= self.max_grid_breakthrough:
            self._trigger(
                f"5分钟内突破{len(self.grid_breakthroughs)}层网格"
            )
    
    def _trigger(self, reason):
        """触发紧急暂停"""
        if not self.is_paused:
            self.is_paused = True
            self.pause_reason = reason
            # 发送警报
            self._send_alert(reason)
    
    def _send_alert(self, reason):
        """发送警报通知"""
        alert_message = f"""
⚠️【紧急暂停】网格交易系统已暂停

暂停原因: {reason}
暂停时间: {self._get_current_time()}

系统已执行:
1. ✅ 取消所有挂单
2. ✅ 保持现有持仓（就地卧倒）
3. ✅ 发送此警报

请检查系统状态后手动恢复。
"""
        # 调用飞书推送
        # notifier.send(alert_message)
    
    def resume(self):
        """恢复系统"""
        self.is_paused = False
        self.api_error_count = 0
        self.grid_breakthroughs = []
        self.pause_reason = None
    
    def _get_current_time(self):
        from datetime import datetime
        return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
```

```
1. 确认网络/系统已恢复正常
```

## 5. 滑点保护机制

### 5.1 适用场景

滑点保护主要在以下场景启用：
- 硬止损触发时平仓
- 紧急暂停恢复后平仓
- 用户手动终止网格时

### 5.2 平仓策略（逐级尝试）

```
第1层：限价单平仓（最优价格）
        → 使用当前买一/卖一价挂单
        → 等待3秒

第2层：对手方最优价格（次优）
        → 若3秒内未成交，改用对手方最优价格
        → 再等待2秒

第3层：市价单（最后手段）
        → 若仍未成交，使用市价单强制平仓
```

### 5.3 具体实现

```python
class SlippageProtection:
    """滑点保护模块"""
    
    def __init__(self, limit_wait=3, fallback_wait=2):
        """
        参数:
            limit_wait: 限价单等待时间（秒）
            fallback_wait: 次优价格等待时间（秒）
        """
        self.limit_wait = limit_wait
        self.fallback_wait = fallback_wait
    
    def close_position(self, position, order_book):
        """
        平仓操作（带滑点保护）
        
        参数:
            position: 持仓信息（数量、方向）
            order_book: 当前订单簿
        
        返回:
            {
                "success": 是否成功,
                "method": 使用的平仓方式,
                "avg_price": 平均成交价,
                "slippage": 滑点比例
            }
        """
        import time
        
        qty = abs(position["quantity"])
        is_long = position["quantity"] > 0
        
        # 第1层：限价单
        if is_long:
            limit_price = order_book["bid1"]  # 买一价
        else:
            limit_price = order_book["ask1"]  # 卖一价
        
        order_id = self._place_limit_order(limit_price, qty, is_long)
        
        # 等待成交
        time.sleep(self.limit_wait)
        
        order_status = self._get_order_status(order_id)
        
        if order_status["filled_qty"] == qty:
            return {
                "success": True,
                "method": "限价单",
                "avg_price": order_status["avg_price"],
                "slippage": abs(order_status["avg_price"] - limit_price) / limit_price
            }
        
        # 第2层：对手方最优价格
        if is_long:
            fallback_price = order_book["ask1"]  # 对手方卖一
        else:
            fallback_price = order_book["bid1"]  # 对手方买一
        
        remaining_qty = qty - order_status["filled_qty"]
        self._cancel_order(order_id)
        
        fallback_order_id = self._place_limit_order(
            fallback_price, remaining_qty, is_long
        )
        
        time.sleep(self.fallback_wait)
        
        fallback_status = self._get_order_status(fallback_order_id)
        
        if fallback_status["filled_qty"] == remaining_qty:
            return {
                "success": True,
                "method": "对手方最优价",
                "avg_price": self._calc_avg_price(
                    order_status, fallback_status
                ),
                "slippage": self._calc_slippage(
                    order_status, fallback_status, limit_price
                )
            }
        
        # 第3层：市价单
        remaining_qty = qty - order_status["filled_qty"] - \
                        fallback_status["filled_qty"]
        self._cancel_order(fallback_order_id)
        
        market_order = self._place_market_order(remaining_qty, is_long)
        
        return {
            "success": True,
            "method": "市价单",
            "avg_price": self._calc_total_avg(
                order_status, fallback_status, market_order
            ),
            "slippage": "市价单，滑点较大"
        }
```

## 6. 动态仓位调整

### 6.1 波动率平价原理

动态仓位调整的核心思想是：**固定名义本金，根据波动率调整实际开仓保证金，确保每单位风险恒定**。

```
动态仓位 = 固定名义本金 / (ATR × 系数)
```

### 6.2 计算逻辑

```python
class DynamicPositionSizing:
    """动态仓位调整"""
    
    def __init__(self, base_notional, atr_coefficient=1.0):
        """
        参数:
            base_notional: 基础名义本金
            atr_coefficient: ATR系数
        """
        self.base_notional = base_notional
        self.atr_coefficient = atr_coefficient
    
    def calculate_margin(self, atr_smooth, price, leverage):
        """
        计算建议保证金
        
        参数:
            atr_smooth: 平滑ATR
            price: 当前价格
            leverage: 杠杆倍数
        
        返回:
            {
                "suggested_margin": 建议保证金,
                "notional": 名义价值,
                "risk_unit": 单位风险,
                "position_ratio": 仓位比例
            }
        """
        # 单位风险（名义价值 × 波动率）
        risk_unit = self.base_notional * (atr_smooth / price)
        
        # 建议保证金
        suggested_margin = self.base_notional / leverage
        
        return {
            "suggested_margin": suggested_margin,
            "notional": self.base_notional,
            "risk_unit": risk_unit,
            "position_ratio": suggested_margin / (price / leverage)
        }
```

### 6.3 半自动模式下的应用

在半自动信号灯模式下，系统不直接操作资金，而是提供**资金配置建议**：

```
💰 资金配置建议
当前波动率: ATR = 1500 (基准 = 2000, 75%)
建议:
- 波动率降低，可适当增加仓位
- 建议保证金: 600 USDT (基准500U × 1.2)
- 若维持500U保证金，名义价值不变，单位风险增加
```

### 6.4 仓位调整决策表

| ATR相对基准 | 仓位建议 | 说明 |
|------------|---------|------|
| < 70% | 增加仓位 | 波动率低，风险小，可增加敞口 |
| 70%~130% | 维持仓位 | 波动率正常，保持当前仓位 |
| 130%~180% | 减少仓位 | 波动率升高，降低敞口 |
| > 180% | 大幅减仓 | 波动率极高，准备暂停 |

## 7. 风险场景与应对策略

### 7.1 常见风险场景

| 风险场景 | 触发条件 | 应对策略 | 优先级 |
|---------|---------|---------|--------|
| 单边行情 | 价格持续单向移动，突破多层网格 | 移动止盈/硬止损 | 高 |
| 强趋势 | ADX ≥ 40 | 暂停网格，空仓观望 | 高 |
| 网络异常 | API无响应或延迟 > 3秒 | 紧急暂停 | 高 |
| 高手续费磨损 | 网格过于密集，频繁交易 | 减少网格数量，增加间距 | 中 |
| 资金费率成本 | 持仓方向与资金费率相反 | 调整网格方向或暂停 | 中 |
| 极端行情滑点 | 流动性骤降，买卖价差扩大 | 滑点保护机制 | 高 |
| 状态频繁切换 | 市场在震荡和趋势间快速切换 | 状态确认机制（连续3次） | 中 |
| 参数过拟合 | 历史回测表现好，实盘差 | 小资金试运行，持续监控 | 低 |

### 7.2 资金费率风险管理

| 场景 | 资金费率 | 建议 |
|------|---------|------|
| 多头网格 + 正费率 | 支付资金费 | 减少网格数量，缩短持仓时间 |
| 多头网格 + 负费率 | 收取资金费 | 保持或增加网格 |
| 空头网格 + 正费率 | 收取资金费 | 保持或增加网格 |
| 空头网格 + 负费率 | 支付资金费 | 减少网格数量，缩短持仓时间 |

### 7.3 杠杆风险管理

| 杠杆倍数 | 风险级别 | 建议 |
|---------|---------|------|
| 1x~3x | 低 | 适合大资金，波动容忍度高 |
| 5x~10x | 中 | 推荐范围，平衡收益与风险 |
| 15x~20x | 高 | 小资金可尝试，需严格止损 |
| >20x | 极高 | 不推荐，容易强平 |

### 7.4 极端行情应对流程

```
检测到极端行情（ADX≥40 或 价格突破>10%）
        ↓
1. 立即推送"强趋势暂停"信号
        ↓
2. 用户手动终止当前网格
        ↓
3. 空仓观望
        ↓
4. 每1小时重新评估市场状态
        ↓
5. 当ADX<40且状态确认3次后，推送新网格配置
        ↓
6. 用户确认后重新创建网格
```

## 8. 完整风险管理流程

### 8.1 风险管理主流程

```python
class RiskManager:
    """风险管理器（总控）"""
    
    def __init__(self, config):
        self.initial_margin = config.get("initial_margin", 500)
        self.leverage = config.get("leverage", 10)
        
        # 初始化各风险管理模块
        self.hard_stop = HardStopLoss(
            self.initial_margin,
            stop_loss_ratio=config.get("stop_loss_ratio", 0.08)
        )
        
        self.trailing_tp = TrailingTakeProfit(
            self.initial_margin,
            trigger_ratio=config.get("trailing_trigger", 0.15),
            trail_ratio=config.get("trail_ratio", 0.05)
        )
        
        self.emergency_pause = EmergencyPause(
            max_api_errors=config.get("max_api_errors", 3),
            max_api_delay=config.get("max_api_delay", 3.0),
            max_grid_breakthrough=config.get("max_breakthrough", 3),
            breakthrough_window=config.get("breakthrough_window", 300)
        )
        
        self.slippage_protection = SlippageProtection()
        
        self.dynamic_sizing = DynamicPositionSizing(
            base_notional=self.initial_margin * self.leverage
        )
    
    def evaluate(self, market_data, position_data, system_data):
        """
        综合风险评估
        
        参数:
            market_data: 市场数据（价格、ATR、ADX等）
            position_data: 持仓数据（盈亏、方向等）
            system_data: 系统数据（API状态、网络状态等）
        
        返回:
            {
                "risk_level": 风险级别,
                "action": 建议动作,
                "details": 详细信息
            }
        """
        risk_level = "low"
        action = "continue"
        details = []
        
        # 1. 检查紧急暂停
        if system_data.get("api_error"):
            self.emergency_pause.record_api_error()
        if system_data.get("api_delay"):
            self.emergency_pause.record_api_delay(
                system_data["api_delay"]
            )
        if system_data.get("grid_breakthrough"):
            self.emergency_pause.record_grid_breakthrough(
                system_data["timestamp"]
            )
        
        if self.emergency_pause.is_paused:
            return {
                "risk_level": "critical",
                "action": "emergency_pause",
                "reason": self.emergency_pause.pause_reason
            }
        
        # 2. 检查硬止损
        stop_status = self.hard_stop.get_status(
            position_data["realized_pnl"],
            position_data["unrealized_pnl"]
        )
        
        if stop_status["is_triggered"]:
            return {
                "risk_level": "critical",
                "action": "hard_stop_loss",
                "total_pnl": stop_status["total_pnl"],
                "pnl_percent": stop_status["pnl_percent"]
            }
        
        # 更新硬止损距离
        if stop_status["distance_to_stop"] < \
           self.initial_margin * 0.04:  # 距离止损<4%
            risk_level = "high"
            details.append("接近硬止损线")
        
        # 3. 检查移动止盈
        trailing_result = self.trailing_tp.update(
            market_data["current_price"],
            position_data["total_pnl"],
            market_data["market_state"]
        )
        
        if trailing_result["is_triggered"]:
            return {
                "risk_level": "medium",
                "action": "trailing_take_profit",
                "stop_price": trailing_result["new_stop_price"]
            }
        
        if trailing_result["is_active"]:
            action = "update_stop_price"
            details.append("移动止盈已激活，建议更新止盈价")
        
        # 4. 动态仓位建议
        sizing_suggestion = self.dynamic_sizing.calculate_margin(
            market_data["atr_smooth"],
            market_data["current_price"],
            self.leverage
        )
        
        # 5. 综合评估
        if risk_level == "low":
            if details:
                risk_level = "medium"
        
        return {
            "risk_level": risk_level,
            "action": action,
            "details": details,
            "stop_status": stop_status,
            "trailing_status": {
                "is_active": self.trailing_tp.is_active,
                "peak_price": self.trailing_tp.peak_price,
                "new_stop_price": trailing_result.get("new_stop_price")
            },
            "sizing_suggestion": sizing_suggestion
        }
```
