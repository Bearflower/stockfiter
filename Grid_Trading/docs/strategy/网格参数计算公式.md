## 1. 概述

### 1.1 计算目标

网格参数计算模块根据市场状态识别结果，动态计算最优网格参数，包括：
- 网格价格区间（上边界、下边界）
- 网格数量
- 网格模式（等差/等比）
- 止盈止损价格（终止最低价、终止最高价）
- 停止上移/下移价格

### 1.2 计算流程图

```
┌─────────────────────────────┐
│  输入: 市场状态 + ATR + k    │
└──────────────┬──────────────┘
               ↓
    ┌──────────────────────┐
    │ 计算价格区间          │
    │ (上边界 / 下边界)     │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 计算网格数量 N        │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 选择网格模式          │
    │ (等差 / 等比)         │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 计算止盈止损价格      │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 计算停止上移/下移价格 │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 验证每格利润率 ≥ 1%  │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 验证每格张数 ≥ 1     │
    └──────────┬───────────┘
               ↓
    ┌──────────────────────┐
    │ 输出: 完整网格参数    │
    └──────────────────────┘
```

## 2. 输入数据

### 2.1 核心输入

| 参数 | 来源 | 说明 |
|------|------|------|
| 当前标记价格 \( P \) | 15分钟K线最新收盘价 | 用于计算所有价格基准 |
| 平滑 ATR \( ATR_{smooth} \) | 市场状态识别模块 | `ATR_smooth = EMA(ATR(14), 14)` |
| 最终市场状态 | 市场状态识别模块 | 震荡 / 上升趋势 / 下降趋势 / 强趋势暂停 |
| 趋势强度系数 \( k \) | 市场状态识别模块 | 仅在趋势状态下有效 |
| 基准 ATR \( ATR_{base} \) | 市场状态识别模块 | 过去90天ATR均值（滚动窗口） |

### 2.2 用户配置输入

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 杠杆 \( L \) | 10 | 用户自定义 |
| 总保证金 \( M \) | 500 USDT | 用户自定义 |
| 基准网格数 | 30 | 可配置 |
| 最小网格数 | 20 | 可调（保守模式建议5） |
| 最大网格数 | 50 | 固定 |

## 3. 价格区间计算

### 3.1 计算公式

根据市场状态，采用不同的价格区间计算公式：

| 状态 | 下边界 | 上边界 | 区间宽度 |
|------|--------|--------|---------|
| **震荡** | \( P - 2 \times ATR_{smooth} \) | \( P + 2 \times ATR_{smooth} \) | \( 4 \times ATR_{smooth} \) |
| **上升趋势** | \( P - 1.5 \times ATR_{smooth} \) | \( P + 4 \times ATR_{smooth} \) | \( 5.5 \times ATR_{smooth} \) |
| **下降趋势** | \( P - 4 \times ATR_{smooth} \) | \( P + 1.5 \times ATR_{smooth} \) | \( 5.5 \times ATR_{smooth} \) |

### 3.2 逻辑解释

**震荡市场**：
- 上下边界对称，各为 2 倍 ATR
- 适合标准双向网格，多空均等获利

**上升趋势**：
- **上边界更深**（4倍ATR）：给多头更多上涨空间
- **下边界更浅**（1.5倍ATR）：减少做空仓位，降低下跌风险
- 配合"上移功能"，趋势延续时可继续获利

**下降趋势**：
- **下边界更深**（4倍ATR）：给空头更多下跌空间
- **上边界更浅**（1.5倍ATR）：减少做多仓位，降低上涨风险
- 配合"下移功能"，趋势延续时可继续获利

### 3.3 Python 实现

```python
def calculate_price_range(current_price, atr_smooth, market_state):
    """
    计算网格价格区间
    
    参数:
        current_price: 当前标记价格 P
        atr_smooth: 平滑 ATR 值
        market_state: "震荡" | "上升趋势" | "下降趋势"
    
    返回:
        (lower_bound, upper_bound)
    """
    if market_state == "震荡":
        lower_bound = current_price - 2 * atr_smooth
        upper_bound = current_price + 2 * atr_smooth
    
    elif market_state == "上升趋势":
        lower_bound = current_price - 1.5 * atr_smooth
        upper_bound = current_price + 4 * atr_smooth
    
    elif market_state == "下降趋势":
        lower_bound = current_price - 4 * atr_smooth
        upper_bound = current_price + 1.5 * atr_smooth
    
    else:
        raise ValueError(f"未知的市场状态: {market_state}")
    
    # 安全校验
    min_width = 2 * atr_smooth  # 最小宽度至少为 2 倍 ATR
    if upper_bound - lower_bound < min_width:
        # 强制扩展边界
        center = (upper_bound + lower_bound) / 2
        half_width = min_width / 2
        lower_bound = center - half_width
        upper_bound = center + half_width
    
    return lower_bound, upper_bound
```

### 3.4 计算示例

假设当前 BTCUSDT 价格 `P = 69500`，`ATR_smooth = 1500`：

| 状态 | 下边界 | 上边界 | 宽度 |
|------|--------|--------|------|
| 震荡 | 69500 - 2×1500 = **66500** | 69500 + 2×1500 = **72500** | 6000 |
| 上升 | 69500 - 1.5×1500 = **67250** | 69500 + 4×1500 = **75500** | 8250 |
| 下降 | 69500 - 4×1500 = **63500** | 69500 + 1.5×1500 = **71750** | 8250 |

## 4. 网格数量计算

### 4.1 基础公式

```
N = round(基准网格数 × (基准ATR / ATR_smooth))
```

### 4.2 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 基准网格数 | 30 | 波动率正常时的网格数量 |
| 基准ATR | 过去90天ATR均值 | 长期波动率参考 |
| ATR_smooth | 当前平滑ATR | 短期波动率 |

### 4.3 范围限制

计算出的 N 必须限制在 [20, 50] 范围内：

```python
N = max(20, min(50, N))
```

### 4.4 逻辑解释

- **波动率升高**（当前ATR > 基准ATR）→ N 减少 → 格子变宽 → 减少被套仓位
- **波动率降低**（当前ATR < 基准ATR）→ N 增加 → 格子变密 → 增加获利机会

### 4.5 计算示例

假设基准ATR = 2000，当前ATR_smooth = 1500：

```
N = round(30 × (2000 / 1500)) = round(40) = 40
N = max(20, min(50, 40)) = 40
```

假设基准ATR = 1500，当前ATR_smooth = 2500：

```
N = round(30 × (1500 / 2500)) = round(18) = 18
N = max(20, min(50, 18)) = 20   # 触发下限
```

### 4.6 Python 实现

```python
def calculate_grid_count(base_atr, atr_smooth, base_grid_count=30, 
                         min_count=20, max_count=50):
    """
    计算网格数量
    
    参数:
        base_atr: 基准 ATR（过去90天均值）
        atr_smooth: 当前平滑 ATR
        base_grid_count: 基准网格数（默认30）
        min_count: 最小网格数（默认20）
        max_count: 最大网格数（默认50）
    
    返回:
        grid_count: 网格数量
    """
    if atr_smooth <= 0:
        atr_smooth = base_atr  # 避免除零
    
    grid_count = round(base_grid_count * (base_atr / atr_smooth))
    grid_count = max(min_count, min(max_count, grid_count))
    
    return grid_count
```

## 5. 网格模式选择

### 5.1 判定规则

根据价格区间的振幅百分比决定使用等差网格还是等比网格：

```
振幅百分比 = (上边界 - 下边界) / P
```

| 振幅百分比 | 网格模式 | 原因 |
|-----------|---------|------|
| < 0.3 (30%) | **等差网格** | 价格区间较小，等间距即可 |
| ≥ 0.3 (30%) | **等比网格** | 价格区间较大，等比例更合理 |

### 5.2 Python 实现

```python
def select_grid_mode(lower_bound, upper_bound, current_price, threshold=0.3):
    """
    选择网格模式
    
    参数:
        lower_bound: 下边界
        upper_bound: 上边界
        current_price: 当前价格
        threshold: 切换阈值（默认0.3）
    
    返回:
        "等差" 或 "等比"
    """
    amplitude = (upper_bound - lower_bound) / current_price
    
    if amplitude < threshold:
        return "等差"
    else:
        return "等比"
```

### 5.3 两种模式的差异

| 特性 | 等差网格 | 等比网格 |
|------|---------|---------|
| 网格间距 | 固定值 | 按比例递增 |
| 适用场景 | 区间较小（<30%） | 区间较大（≥30%） |
| 计算方式 | 间距 = (上边界-下边界) / N | 比例 = (上边界/下边界)^(1/N) |
| 利润率 | 下方利润率更高 | 各层利润率相同 |

## 6. 止盈止损价格计算

### 6.1 终止最低价（硬止损线）

**计算公式**：

```
终止最低价 = 下边界 - 2 × ATR_smooth
```

**逻辑**：
- 在网格下边界下方再留 2 倍 ATR 的缓冲区域
- 一旦价格跌破此线，说明网格底部被有效击穿，立即终止

### 6.2 终止最高价（硬止盈线）

**计算公式**：

```
终止最高价 = 上边界 + 2 × ATR_smooth
```

**逻辑**：
- 在网格上边界上方再留 2 倍 ATR 的缓冲区域
- 一旦价格突破此线，说明网格顶部被有效突破，止盈终止

### 6.3 动态调整逻辑

#### 终止最低价动态调整

**仅在盈利状态下考虑上移**，保守调整：

```python
def adjust_terminate_low(current_terminate_low, current_price, atr_smooth, 
                         total_pnl_percent):
    """
    动态调整终止最低价
    
    规则：仅在盈利时上移，亏损时绝不向下移动
    """
    if total_pnl_percent > 0:  # 盈利状态
        new_terminate_low = max(
            current_terminate_low,
            current_price - 3 * atr_smooth  # 保留3倍ATR缓冲
        )
        return new_terminate_low
    else:
        # 亏损状态，维持原值不变
        return current_terminate_low
```

**触发条件**：
- 盈利状态下，价格持续上涨，且当前价格已远离原止损线（例如价格 > 原终止最低价 + 2×ATR）
- 最小调整间隔：每4小时最多调整一次

**注意**：亏损时绝不向下移动止损线（避免死扛扩大亏损）

#### 终止最高价动态调整

结合移动止盈机制：

```python
def adjust_terminate_high(current_terminate_high, peak_price, 
                          total_pnl_percent, trailing_trigger=0.15):
    """
    动态调整终止最高价（移动止盈）
    
    参数:
        current_terminate_high: 当前终止最高价
        peak_price: 本次盈利周期内的最高价
        total_pnl_percent: 总盈亏百分比
        trailing_trigger: 移动止盈启动阈值（默认15%）
    """
    if total_pnl_percent >= trailing_trigger:
        # 移动止盈已启动
        new_terminate_high = min(
            current_terminate_high,
            peak_price * (1 - 0.05)  # 从峰值回撤5%
        )
        return new_terminate_high
    else:
        return current_terminate_high
```

**触发条件**：
- 总盈利首次超过15%（启动移动止盈模式）
- 在移动止盈模式下，价格从最高点回撤，且回撤幅度 ≥ 5%
- 可在每次巡检时重新计算，若新值低于旧值则更新

## 7. 停止上移/下移价格计算

### 7.1 停止上移价格

**仅在上升趋势中启用**。

**计算公式**：

```
停止上移价格 = 上边界 + k × ATR_smooth
```

其中 k 为趋势强度系数（详见《市场状态识别算法》文档）。

**触发条件**（满足任意一条）：
- 价格连续向上突破网格层数 ≥ 3层（在5分钟内）
- ADX > 25（确认有上升趋势）
- 当前价格已超过当前的停止上移价格

**动态调整公式**：

```
新停止上移价格 = max(当前网格上边界 + 上移步长, 上一次的停止上移价格)
上移步长 = k × ATR_smooth
```

**注意**：每次上移后，应将"上一次的停止上移价格"更新为新值，并保存到本地状态。

### 7.2 停止下移价格

**仅在下降趋势中启用**。

**计算公式**：

```
停止下移价格 = 下边界 - k × ATR_smooth
```

**触发条件**（满足任意一条）：
- 价格连续向下突破网格层数 ≥ 3层（在5分钟内）
- ADX > 25（确认有下降趋势）
- 当前价格已低于当前的停止下移价格

**动态调整公式**：

```
新停止下移价格 = min(当前网格下边界 - 下移步长, 上一次的停止下移价格)
下移步长 = k × ATR_smooth
```

**注意**：每次下移后，应更新本地记录。

### 7.3 k 值示例与步长计算

| ADX_1h | k 值 | ATR_smooth=1500 时的步长 |
|--------|------|------------------------|
| 25 | 0.00 | 0（不动） |
| 28 | 0.10 | 150 |
| 32 | 0.23 | 345 |
| 37 | 0.40 | 600 |
| 40 | 0.50 | 750（上限） |

### 7.4 Python 实现

```python
def calculate_stop_move_price(bound, atr_smooth, k_trend, direction="up"):
    """
    计算停止上移/下移价格
    
    参数:
        bound: 网格边界（上边界或下边界）
        atr_smooth: 平滑 ATR
        k_trend: 趋势强度系数
        direction: "up"（上移）或 "down"（下移）
    
    返回:
        stop_move_price: 停止移动价格
    """
    step = k_trend * atr_smooth
    
    if direction == "up":
        return bound + step
    else:
        return bound - step
```

## 8. 6个可调参数的触发条件

### 8.1 参数调整分类

系统中的6个可调参数按**修改方式**分为两类：

| 类别 | 参数 | 修改方式 | API 操作 |
|------|------|---------|---------|
| **需终止重建** | 价格范围（上/下边界） | 终止旧网格 → 创建新网格 | `stop` → `create` |
| **需终止重建** | 网格数量 | 同上 | 同上 |
| **可直接修改** | 停止上移价格 | 调用修改接口 | `update` |
| **可直接修改** | 停止下移价格 | 调用修改接口 | `update` |
| **可直接修改** | 终止最低价格 | 调用修改接口 | `update` |
| **可直接修改** | 终止最高价格 | 调用修改接口 | `update` |

### 8.2 各参数触发条件汇总

#### 参数1：网格交易价格范围（上边界/下边界）

| 触发条件 | 说明 | 阈值 |
|---------|------|------|
| 平滑ATR变化 | 相对于上次调整时的值 | ±20%（保守模式35%） |
| 市场状态变化 | 震荡 ↔ 趋势 | 任何变化 |
| 价格靠近边界 | 价格距边界太近 | < 0.5×ATR_smooth（保守模式1.5×） |

#### 参数2：网格数量

| 触发条件 | 说明 | 阈值 |
|---------|------|------|
| 平滑ATR变化 | 与价格范围调整同步 | ±20%（保守模式35%） |

**注意**：网格数量调整通常与价格范围调整同步进行，避免频繁终止重建。

#### 参数3：停止上移价格

| 触发条件 | 说明 |
|---------|------|
| 连续突破 | 价格连续向上突破网格层数 ≥ 3层（5分钟内） |
| ADX确认 | ADX > 25 |
| 价格突破 | 当前价格 > 当前停止上移价格 |

#### 参数4：停止下移价格

| 触发条件 | 说明 |
|---------|------|
| 连续突破 | 价格连续向下突破网格层数 ≥ 3层（5分钟内） |
| ADX确认 | ADX > 25 |
| 价格突破 | 当前价格 < 当前停止下移价格 |

#### 参数5：终止最低价格

| 触发条件 | 说明 |
|---------|------|
| 盈利状态 | total_PnL > 0，且价格远离原止损线 |
| 最小间隔 | 每4小时最多调整一次 |
| 价格偏离 | 当前价格 > 原终止最低价 + 2×ATR |

#### 参数6：终止最高价格

| 触发条件 | 说明 |
|---------|------|
| 移动止盈启动 | 总盈利 ≥ 15% |
| 价格回撤 | 从最高点回撤 ≥ 5% |
| 巡检更新 | 每次巡检重新计算，新值 < 旧值则更新 |

### 8.3 保守模式参数调整策略

为避免频繁调整导致手续费损耗，引入保守模式：

| 配置项 | 标准模式 | 保守模式 | 说明 |
|--------|---------|---------|------|
| ATR变化阈值 | ±20% | ±35% | 降低敏感度 |
| 边界接近阈值 | 0.5×ATR | 1.5×ATR | 放宽边界 |
| 价格偏离阈值 | - | 10% | 新增：价格偏离网格中心 |
| 终止价格偏离阈值 | - | 15% | 新增：终止价格偏离度 |
| 状态确认次数 | 1次 | 3次 | 连续确认 |
| 最小触发严重性 | - | 0.7 | 综合评分需超过0.7 |

## 9. 利润率验证

### 9.1 币安要求

币安合约网格要求**每格利润率 > 1%**，否则无法创建。

### 9.2 等差网格利润率

```
间距 = (上边界 - 下边界) / N
每格利润率 = 间距 / P × 100%
```

### 9.3 等比网格利润率

```
比例 = (上边界 / 下边界) ^ (1/N)
每格利润率 = (比例 - 1) × 100%
```

### 9.4 自动调整逻辑

```python
def validate_profit_rate(lower_bound, upper_bound, grid_count, current_price, 
                         grid_mode, min_rate=0.01, min_count=20):
    """
    验证每格利润率，不满足则自动减少网格数量
    
    参数:
        lower_bound: 下边界
        upper_bound: 上边界
        grid_count: 网格数量
        current_price: 当前价格
        grid_mode: "等差" 或 "等比"
        min_rate: 最小利润率（默认1%）
        min_count: 最小网格数（默认20）
    
    返回:
        (is_valid, grid_count, profit_rate)
    """
    while grid_count >= min_count:
        if grid_mode == "等差":
            spacing = (upper_bound - lower_bound) / grid_count
            profit_rate = spacing / current_price
        else:  # 等比
            ratio = (upper_bound / lower_bound) ** (1 / grid_count)
            profit_rate = ratio - 1
        
        if profit_rate >= min_rate:
            return True, grid_count, profit_rate
        
        grid_count -= 1  # 减少网格数量
    
    # 即使减到最小仍不满足
    return False, grid_count, profit_rate
```

### 9.5 验证示例

假设下边界=66500，上边界=72500，N=30，P=69500：

**等差网格**：
```
间距 = (72500 - 66500) / 30 = 200
利润率 = 200 / 69500 = 0.288% < 1% → 不满足
```

需要减少网格数量直到满足：

```
N=20: 间距 = 6000/20 = 300, 利润率 = 300/69500 = 0.43% → 不满足
...
N=9:  间距 = 6000/9 ≈ 667, 利润率 = 667/69500 = 0.96% → 不满足
N=8:  间距 = 6000/8 = 750, 利润率 = 750/69500 = 1.08% → 满足
```

### 9.6 警告推送

若利润率不满足，系统应：
1. 自动减少网格数量到满足条件的最小值
2. 若减到最小值（20）仍不满足，推送警告消息
3. 警告内容应包含建议（增加保证金、减少网格数量、提高杠杆）

## 10. 仓位可行性验证与张数计算

### 10.1 币安合约最小交易限制

- BTCUSDT 永续合约：最小下单量 **1 张**（1 张 = 1 USDT 面值）
- 创建网格时，每格下单数量必须是整数张数，且 ≥ 1

### 10.2 张数计算公式

用户创建网格时需提供杠杆 \( L \)、总保证金 \( M \)、网格数量 \( N \)。

```
总名义价值 = M × L
每格名义价值 = (M × L) / N
每格下单张数 = floor(每格名义价值 / P)
```

### 10.3 计算示例

**默认参数（不可行）**：

```
M = 500, L = 10, N = 30, P = 69500

总名义价值 = 500 × 10 = 5000 USDT
每格名义价值 = 5000 / 30 ≈ 166.67 USDT
每格张数 = floor(166.67 / 69500) = 0 → 不可行！
```

**可行参数（减少网格数量）**：

```
M = 500, L = 10, N = 5, P = 69500

总名义价值 = 5000 USDT
每格名义价值 = 5000 / 5 = 1000 USDT
每格张数 = floor(1000 / 69500) = 0 → 仍不可行！
```

**可行参数（增加保证金）**：

```
M = 34750, L = 10, N = 5, P = 69500

总名义价值 = 347500 USDT
每格名义价值 = 347500 / 5 = 69500 USDT
每格张数 = floor(69500 / 69500) = 1 → 可行！
```

### 10.4 最小保证金公式

给定 N、L、P，计算最小所需保证金：

```
M_min = (N × P) / L
```

### 10.5 Python 实现

```python
import math

def validate_position_size(price, grid_count, leverage, margin, min_qty=1):
    """
    验证仓位可行性
    
    参数:
        price: 当前价格
        grid_count: 网格数量
        leverage: 杠杆倍数
        margin: 总保证金
        min_qty: 最小下单张数（默认1）
    
    返回:
        (is_feasible, message, suggested_params)
    """
    total_nominal = margin * leverage
    nominal_per_grid = total_nominal / grid_count
    qty_per_grid = nominal_per_grid / price
    
    if qty_per_grid >= min_qty:
        actual_qty = math.floor(qty_per_grid)
        return True, f"每格{qty_per_grid:.2f}张（取整后{actual_qty}张）", {}
    else:
        # 计算最小所需保证金
        min_margin = (min_qty * price * grid_count) / leverage
        
        # 计算最大可行网格数量
        max_feasible_count = int(margin * leverage / price)
        if max_feasible_count < 1:
            max_feasible_count = 0
        
        return False, (
            f"每格仅{qty_per_grid:.2f}张，不足{min_qty}张。\n"
            f"建议方案：\n"
            f"1. 将保证金增至 {min_margin:.0f} USDT\n"
            f"2. 或减少网格数量至 {max_feasible_count} 格\n"
            f"3. 或提高杠杆倍数（风险增加）"
        ), {
            "min_margin": min_margin,
            "max_feasible_count": max_feasible_count
        }
```

## 11. 完整计算流程

### 11.1 主流程伪代码

```python
class GridParameterCalculator:
    def __init__(self):
        self.base_grid_count = 30
        self.min_grid_count = 20
        self.max_grid_count = 50
        self.min_profit_rate = 0.01  # 1%
        self.amplitude_threshold = 0.3  # 30%
    
    def calculate(self, current_price, atr_smooth, base_atr, market_state, 
                  k_trend, leverage=10, margin=500):
        """
        计算完整网格参数
        
        参数:
            current_price: 当前标记价格
            atr_smooth: 平滑 ATR
            base_atr: 基准 ATR
            market_state: 市场状态
            k_trend: 趋势强度系数
            leverage: 杠杆倍数
            margin: 总保证金
        
        返回:
            包含所有网格参数的字典
        """
        # 第1步：计算价格区间
        lower_bound, upper_bound = calculate_price_range(
            current_price, atr_smooth, market_state
        )
        
        # 第2步：计算网格数量
        grid_count = calculate_grid_count(
            base_atr, atr_smooth,
            base_grid_count=self.base_grid_count,
            min_count=self.min_grid_count,
            max_count=self.max_grid_count
        )
        
        # 第3步：选择网格模式
        grid_mode = select_grid_mode(
            lower_bound, upper_bound, current_price,
            threshold=self.amplitude_threshold
        )
        
        # 第4步：验证并调整利润率
        is_valid, grid_count, profit_rate = validate_profit_rate(
            lower_bound, upper_bound, grid_count, current_price,
            grid_mode, min_rate=self.min_profit_rate,
            min_count=self.min_grid_count
        )
        
        if not is_valid:
            # 利润率仍不满足，记录警告
            warning = f"利润率 {profit_rate:.2%} 低于要求 {self.min_profit_rate:.2%}"
        else:
            warning = None
        
        # 第5步：计算止盈止损价格
        terminate_low = lower_bound - 2 * atr_smooth
        terminate_high = upper_bound + 2 * atr_smooth
        
        # 第6步：计算停止上移/下移价格
        stop_move_up = None
        stop_move_down = None
        
        if market_state == "上升趋势":
            stop_move_up = upper_bound + k_trend * atr_smooth
        elif market_state == "下降趋势":
            stop_move_down = lower_bound - k_trend * atr_smooth
        
        # 第7步：验证仓位可行性
        is_feasible, position_msg, suggestions = validate_position_size(
            current_price, grid_count, leverage, margin
        )
        
        # 第8步：计算网格间距
        if grid_mode == "等差":
            grid_spacing = (upper_bound - lower_bound) / grid_count
        else:
            grid_spacing = None  # 等比网格间距不固定
        
        # 第9步：组装结果
        result = {
            "market_state": market_state,
            "current_price": current_price,
            "atr_smooth": atr_smooth,
            "k_trend": k_trend,
            
            # 核心参数
            "lower_bound": lower_bound,
            "upper_bound": upper_bound,
            "grid_count": grid_count,
            "grid_mode": grid_mode,
            "grid_spacing": grid_spacing,
            "profit_rate": profit_rate,
            
            # 止盈止损
            "terminate_low": terminate_low,
            "terminate_high": terminate_high,
            
            # 移动功能
            "stop_move_up": stop_move_up,
            "stop_move_down": stop_move_down,
            
            # 验证结果
            "is_profit_rate_valid": is_valid,
            "is_position_feasible": is_feasible,
            "position_msg": position_msg,
            "warning": warning,
            "suggestions": suggestions
        }
        
        return result
```
