# 数据库设计文档

## 概述

本系统使用 SQLite 作为本地数据库，用于存储交易记录、网格历史、系统状态、风险事件、网格参数调整历史和移动止盈状态等关键数据。所有表结构定义如下。

## 数据库连接

- **数据库类型**: SQLite3 (Python 内置)
- **数据库文件**: `data/database.db`
- **异步支持**: 可选使用 `aiosqlite` 库实现异步操作

---

## 表结构定义

### 1. 交易记录表 (trades)

存储所有交易记录的详细信息。

```sql
CREATE TABLE trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    trade_id TEXT UNIQUE,
    symbol TEXT NOT NULL,
    side TEXT NOT NULL,  -- BUY/SELL
    price REAL NOT NULL,
    quantity REAL NOT NULL,
    fee REAL,
    fee_asset TEXT,
    timestamp DATETIME NOT NULL,
    grid_id TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| trade_id | TEXT | UNIQUE | 交易唯一标识 |
| symbol | TEXT | NOT NULL | 交易对（如 BTCUSDT） |
| side | TEXT | NOT NULL | 交易方向（BUY/SELL） |
| price | REAL | NOT NULL | 成交价格 |
| quantity | REAL | NOT NULL | 成交数量 |
| fee | REAL | | 手续费 |
| fee_asset | TEXT | | 手续费币种 |
| timestamp | DATETIME | NOT NULL | 交易时间 |
| grid_id | TEXT | | 关联的网格ID |
| created_at | DATETIME | DEFAULT CURRENT_TIMESTAMP | 记录创建时间 |

---

### 2. 网格历史表 (grid_history)

记录网格的创建、运行和终止历史。

```sql
CREATE TABLE grid_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    grid_id TEXT UNIQUE,
    symbol TEXT NOT NULL,
    upper_price REAL NOT NULL,
    lower_price REAL NOT NULL,
    grid_count INTEGER NOT NULL,
    investment REAL NOT NULL,
    state TEXT NOT NULL,  -- CREATED, RUNNING, TERMINATED
    market_state TEXT,  -- RANGING, UPTREND, DOWNTREND
    created_at DATETIME NOT NULL,
    terminated_at DATETIME,
    pnl REAL
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| grid_id | TEXT | UNIQUE | 网格唯一标识 |
| symbol | TEXT | NOT NULL | 交易对 |
| upper_price | REAL | NOT NULL | 网格上边界价格 |
| lower_price | REAL | NOT NULL | 网格下边界价格 |
| grid_count | INTEGER | NOT NULL | 网格数量 |
| investment | REAL | NOT NULL | 投入资金 |
| state | TEXT | NOT NULL | 网格状态（CREATED/RUNNING/TERMINATED） |
| market_state | TEXT | | 市场状态（RANGING/UPTREND/DOWNTREND） |
| created_at | DATETIME | NOT NULL | 创建时间 |
| terminated_at | DATETIME | | 终止时间 |
| pnl | REAL | | 盈亏 |

---

### 3. 系统状态表 (system_status)

记录系统巡检时的关键状态数据。

```sql
CREATE TABLE system_status (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    market_state TEXT NOT NULL,
    price REAL NOT NULL,
    atr REAL NOT NULL,
    adx REAL NOT NULL,
    ema_fast REAL NOT NULL,
    ema_slow REAL NOT NULL,
    total_pnl REAL,
    account_balance REAL
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| timestamp | DATETIME | NOT NULL | 记录时间 |
| market_state | TEXT | NOT NULL | 市场状态 |
| price | REAL | NOT NULL | 当前价格 |
| atr | REAL | NOT NULL | ATR 值 |
| adx | REAL | NOT NULL | ADX 值 |
| ema_fast | REAL | NOT NULL | 快速 EMA 值 |
| ema_slow | REAL | NOT NULL | 慢速 EMA 值 |
| total_pnl | REAL | | 总盈亏 |
| account_balance | REAL | | 账户余额 |

---

### 4. 风险事件表 (risk_events)

记录所有风险事件的触发和执行信息。

```sql
CREATE TABLE risk_events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    event_type TEXT NOT NULL,  -- STOP_LOSS, TRAILING_PROFIT, EMERGENCY_PAUSE
    trigger_price REAL,
    trigger_pnl REAL,
    action_taken TEXT,
    timestamp DATETIME NOT NULL,
    details TEXT
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| event_type | TEXT | NOT NULL | 事件类型（STOP_LOSS/TRAILING_PROFIT/EMERGENCY_PAUSE） |
| trigger_price | REAL | | 触发价格 |
| trigger_pnl | REAL | | 触发时盈亏 |
| action_taken | TEXT | | 采取的行动 |
| timestamp | DATETIME | NOT NULL | 事件时间 |
| details | TEXT | | 详细信息（JSON 格式） |

---

### 5. 网格参数调整历史表 (grid_parameter_adjustments)

记录网格参数的每次调整历史。

```sql
CREATE TABLE grid_parameter_adjustments (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    grid_id TEXT NOT NULL,
    timestamp DATETIME NOT NULL,
    parameter_name TEXT NOT NULL,  -- upper_price, lower_price, grid_count, etc.
    old_value REAL,
    new_value REAL,
    trigger_reason TEXT,  -- ATR_CHANGE, STATE_CHANGE, EDGE_APPROACH, etc.
    market_state TEXT,
    atr_value REAL,
    details TEXT
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| grid_id | TEXT | NOT NULL | 关联的网格ID |
| timestamp | DATETIME | NOT NULL | 调整时间 |
| parameter_name | TEXT | NOT NULL | 参数名称（upper_price/lower_price/grid_count 等） |
| old_value | REAL | | 调整前的值 |
| new_value | REAL | | 调整后的值 |
| trigger_reason | TEXT | | 触发原因（ATR_CHANGE/STATE_CHANGE/EDGE_APPROACH 等） |
| market_state | TEXT | | 调整时的市场状态 |
| atr_value | REAL | | 调整时的 ATR 值 |
| details | TEXT | | 详细信息 |

---

### 6. 移动止盈状态表 (trailing_profit_state)

记录移动止盈的实时状态。

```sql
CREATE TABLE trailing_profit_state (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    grid_id TEXT NOT NULL,
    activated_at DATETIME,
    peak_price REAL,
    peak_pnl_percent REAL,
    current_stop_price REAL,
    last_updated DATETIME NOT NULL
);
```

**字段说明**:
| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 自增主键 |
| grid_id | TEXT | NOT NULL | 关联的网格ID |
| activated_at | DATETIME | | 移动止盈激活时间 |
| peak_price | REAL | | 记录的最高价格（peak_price） |
| peak_pnl_percent | REAL | | 峰值盈亏百分比 |
| current_stop_price | REAL | | 当前止损价格 |
| last_updated | DATETIME | NOT NULL | 最后更新时间 |

## 索引建议

为提高查询性能，建议创建以下索引：

```sql
-- 交易记录表索引
CREATE INDEX idx_trades_symbol ON trades(symbol);
CREATE INDEX idx_trades_grid_id ON trades(grid_id);
CREATE INDEX idx_trades_timestamp ON trades(timestamp);

-- 网格历史表索引
CREATE INDEX idx_grid_history_state ON grid_history(state);
CREATE INDEX idx_grid_history_market_state ON grid_history(market_state);

-- 系统状态表索引
CREATE INDEX idx_system_status_timestamp ON system_status(timestamp);

-- 风险事件表索引
CREATE INDEX idx_risk_events_type ON risk_events(event_type);
CREATE INDEX idx_risk_events_timestamp ON risk_events(timestamp);

-- 参数调整历史表索引
CREATE INDEX idx_parameter_adjustments_grid_id ON grid_parameter_adjustments(grid_id);
CREATE INDEX idx_parameter_adjustments_timestamp ON grid_parameter_adjustments(timestamp);

-- 移动止盈状态表索引
CREATE INDEX idx_trailing_profit_grid_id ON trailing_profit_state(grid_id);
```

## 数据字典

### 枚举值说明

**market_state（市场状态）**:
- `RANGING`: 震荡市场
- `UPTREND`: 上升趋势
- `DOWNTREND`: 下降趋势

**grid_state（网格状态）**:
- `CREATED`: 已创建
- `RUNNING`: 运行中
- `TERMINATED`: 已终止

**event_type（事件类型）**:
- `STOP_LOSS`: 止损触发
- `TRAILING_PROFIT`: 移动止盈触发
- `EMERGENCY_PAUSE`: 紧急暂停

**parameter_name（参数名称）**:
- `upper_price`: 网格上边界
- `lower_price`: 网格下边界
- `grid_count`: 网格数量
- `stop_up_price`: 停止上移价格
- `stop_down_price`: 停止下移价格
- `terminate_low_price`: 网格终止最低价格
- `terminate_high_price`: 网格终止最高价格

**trigger_reason（触发原因）**:
- `ATR_CHANGE`: ATR 变化
- `STATE_CHANGE`: 市场状态变化
- `EDGE_APPROACH`: 价格接近边界
- `LAYER_BREAK`: 突破层数
- `PROFIT_STATUS`: 盈利状态
