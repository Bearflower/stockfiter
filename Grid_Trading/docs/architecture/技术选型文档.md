# 技术选型文档

## 编程语言
- **Python 3.8+**
  - 理由：丰富的量化交易生态，良好的异步支持，开发效率高
  - 最低版本：3.8（支持asyncio成熟特性）

## 核心依赖库

### 网络通信
- **aiohttp** (>=3.8.0)
  - 异步HTTP客户端/服务器
  - 用于REST API调用
- **websockets** (>=12.0)
  - WebSocket客户端库
  - 用于实时数据订阅

### 数据处理
- **pandas** (>=1.5.0)
  - 时间序列数据处理
  - K线数据分析
- **numpy** (>=1.23.0)
  - 数值计算
  - 技术指标计算

### 技术指标计算
- **TA-Lib** (推荐，可选)
  - 专业的技术分析库
  - 提供ADX、ATR、EMA等标准实现
- **备用方案**: 使用pandas/numpy自行实现
  - 避免TA-Lib的安装复杂性
  - 自定义指标计算逻辑

### 配置管理
- **PyYAML** (>=6.0)
  - YAML配置文件解析
  - 策略参数配置

### 数据库
- **SQLite3** (Python内置)
  - 轻量级，无需单独部署
  - 用于存储交易记录、状态历史
- **备用方案**: sqlite3 + aiosqlite
  - 异步SQLite操作

### 日志管理
- **Python logging** (标准库)
  - 结构化日志输出
  - 文件和控制台日志

### 监控报警
- **requests** (>=2.28.0)
  - 同步HTTP请求（用于报警）
  - 调用钉钉/Telegram API
- **备用方案**: aiohttp（统一网络库）

### 开发工具
- **pytest** (>=7.0)
  - 单元测试框架
- **pytest-asyncio** (>=0.21.0)
  - 异步测试支持
- **black** (>=22.0)
  - 代码格式化
- **flake8** (>=6.0)
  - 代码规范检查
- **mypy** (>=1.0)
  - 静态类型检查

## 架构模式

### 异步框架
- **asyncio** (Python内置)
  - 事件驱动异步编程
  - 协程并发处理
- **设计模式**: 事件循环 + 协程任务

### 模块化设计
- **面向接口编程**
- **依赖注入**（简化版）
- **单一职责原则**

## 数据流设计

### 实时数据流
```
币安WebSocket → 数据解析器 → 指标计算器 → 策略引擎
```

### 控制流
```
定时器 → 巡检任务 → 状态判断 → 参数计算 → API调用
```

### 状态管理
```
内存状态 + SQLite持久化 → 状态恢复
```

## 部署环境

### 运行时环境
- **操作系统**: Linux (Ubuntu 20.04+)
- **Python环境**: venv或conda
- **进程管理**: systemd或supervisor

### 网络要求
- 稳定的互联网连接
- 低延迟访问币安服务器
- 防火墙开放WebSocket端口

## 备选技术方案对比

### 网络库选择
| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| python-binance | 封装完善，易用 | 更新滞后，灵活性差 | ❌ |
| ccxt | 多交易所支持 | 币安特有功能支持有限 | ❌ |
| aiohttp+websockets | 灵活性高，控制力强 | 需要自行封装 | ✅ |

### 指标计算选择
| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| TA-Lib | 专业，标准实现 | 安装复杂，依赖C库 | ⚠️ 可选 |
| 自行实现 | 可控，无外部依赖 | 需要测试验证 | ✅ 主要 |

### 数据库选择
| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| SQLite | 轻量，无需部署 | 并发性能有限 | ✅ |
| PostgreSQL | 性能好，功能强 | 需要单独部署 | ❌ |
| Redis | 速度快 | 持久化较弱 | ❌ |

## 版本兼容性

### Python版本兼容
- 确保代码在Python 3.8-3.11间兼容
- 使用`async/await`语法
- 避免使用新版特有特性

### 依赖版本管理
- 使用`requirements.txt`固定版本
- 定期更新安全补丁
- 测试主要依赖升级
