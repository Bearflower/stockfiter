# 网格交易系统 - 通用模块使用说明

## 📦 已提取的通用模块

### 1. 通知服务模块

**原位置**: `adaptive_grid_trading/src/monitoring/notifier.py`  
**通用服务**: `common_service/notification_service`  
**改造后**: `adaptive_grid_trading/src/monitoring/notifier_v2.py`

**调用方式**:
```python
from monitoring.notifier_v2 import AlertNotifier

notifier = AlertNotifier()

# 发送网格创建通知
notifier.notify_grid_created(
    grid_id="GRID_001",
    upper_price=50.0,
    lower_price=40.0,
    grid_count=10,
    investment=1000.0
)

# 发送市场状态变化通知
notifier.notify_state_change(
    old_state="震荡",
    new_state="上涨",
    price=45.67,
    adx=25.5
)

# 发送风险事件通知
notifier.notify_risk_event(
    event_type="止损触发",
    trigger_price=42.50,
    trigger_pnl=-0.05,
    action="已卖出平仓"
)
```

**API 端点**: `http://43.156.242.184:8766/api/v1/send`  
**项目标识**: `grid`

**优势**:
- ✅ 统一管理飞书 webhook
- ✅ 支持异步发送（消息队列）
- ✅ 频率限制防止轰炸
- ✅ 统一日志记录
- ✅ 向后兼容，接口不变
