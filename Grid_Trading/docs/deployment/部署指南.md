## 📋 部署前准备

### 1. 服务器要求

- **操作系统**: Linux (Ubuntu 20.04+ 推荐)
- **内存**: 最低 512MB，推荐 1GB+
- **存储**: 最低 100MB
- **网络**: 可访问币安 API

### 2. 服务器软件

- **Docker**: 20.10+
- **Docker Compose**: 2.0+

### 3. 本地软件

- **SSH 客户端**
- **sshpass** (可选，用于自动输入密码)
- **rsync** (用于打包)

### 4. API 密钥准备

#### 4.1 测试网 API 密钥
- 访问：[币安测试网](https://testnet.binancefuture.com)
- 使用 GitHub 账号登录
- 创建 API 密钥
- 启用"读取信息"和"合约交易"权限

#### 4.2 实盘 API 密钥
- 访问：[币安主网](https://www.binance.com)
- 创建 API 密钥
- 启用"读取信息"和"合约交易"权限
- **重要**: 设置 IP 白名单
- **建议**: 限制 API 密钥权限

### 5. 飞书机器人配置

- 创建飞书群机器人
- 获取 Webhook URL
- 配置关键词（报警、通知、网格）
- 验证接收消息正常

## 🔄 运行模式说明

系统支持两种运行模式：

| 模式 | 说明 | API 密钥要求 | 适用场景 |
|------|------|-------------|----------|
| `signal`（信号灯） | 分析市场生成信号，推送通知，不自动执行交易 | 可选（使用公开接口获取 K 线） | 实盘初期、小额测试、需要人工确认 |
| `auto`（全自动） | 自动分析、自动创建/修改/终止网格 | 必填（需要交易权限） | 成熟运行阶段、无人值守 |

### 信号灯模式（推荐初始使用）

- **工作流程**：每小时第35分钟 → 获取K线数据 → 分析市场状态 → 计算网格参数 → 推送飞书通知
- **用户操作**：根据推送的通知，手动在币安网页端创建或修改网格
- **优势**：安全可控、适合学习、风险可控
- **配置**：`system.mode: signal`

### 全自动模式

- **工作流程**：自动分析 → 自动创建/修改网格 → 自动执行交易
- **用户操作**：无需干预，系统全自动运行
- **优势**：省时省力、适合成熟策略
- **配置**：`system.mode: auto`

### 切换模式

修改 `config/config.yaml` 中的 `system.mode` 或设置环境变量 `SYSTEM_MODE`

## 🔧 配置指南

### 1. 环境变量配置

创建 `config/.env` 文件：

```bash
# 信号灯模式（推荐初始使用）
# 无需 API 密钥，使用币安公开接口获取 K 线数据

# 全自动模式（需要 API 密钥）
# 测试网配置
# BINANCE_API_KEY=your_testnet_api_key
# BINANCE_API_SECRET=your_testnet_api_secret

# 实盘配置（部署时修改）
# BINANCE_API_KEY=your_live_api_key
# BINANCE_API_SECRET=your_live_api_secret

# 飞书报警
FEISHU_WEBHOOK=https://open.feishu.cn/open-apis/bot/v2/hook/xxx

# 通知服务（通用模块）
NOTIFICATION_SERVICE_URL=http://43.156.242.184:8766/api/v1
NOTIFICATION_PROJECT=grid
```

### 2. 策略配置

复制配置模板：

```bash
cp config/config.yaml.template config/config.yaml
```

编辑 `config/config.yaml`：

```yaml
exchange:
  testnet: true  # 测试时 true，实盘改 false
  symbol: "BTCUSDT"

strategy:
  indicators:
    adx_period: 14
    adx_trend_threshold: 25
    adx_weak_threshold: 20
    ema_fast: 20
    ema_slow: 50
    atr_period: 14

  grid:
    base_grid_count: 30      # 适中的网格数量
    min_grid_count: 20       # 保守值
    max_grid_count: 50       # 合理上限
    base_atr_window: 90      # 长期参考窗口

  risk:
    hard_stop_loss: -0.08        # -8% 硬止损
    trailing_profit_start: 0.15  # 15% 启动移动止盈
    trailing_profit_retrace: 0.5 # 50% 回撤平仓
    emergency_break_layers: 3    # 紧急熔断层数
    emergency_break_window: 300  # 5 分钟观察窗口
    position_coefficient: 0.5    # 保守仓位系数

monitoring:
  alert:
    enabled: true  # 启用报警
```

### 3. 部署配置

编辑 `.deploy_config` 文件：

```bash
# 修改为你的服务器信息
SERVER_IP="你的服务器 IP"
SERVER_USER="root"
SERVER_PASSWORD="你的服务器密码"
SERVER_PROJECT_PATH="/root/grid_trading"

DOCKER_CONTAINER_NAME="grid-trading"
DOCKER_IMAGE_NAME="grid-trading:latest"

PROJECT_NAME="grid_trading"
DEPLOY_PACKAGE_NAME="deployment_package.tar.gz"
```

### 4. 风险参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| 硬止损 | -8% | 最大亏损为本金的 8% |
| 移动止盈启动 | 15% | 盈利达 15% 后启动 |
| 移动止盈回撤 | 50% | 回撤 50% 时平仓 |
| 仓位系数 | 0.5 | 单次网格不超过总资金 50% |

**⚠️ 风险提示**:
- 建议从小资金开始测试
- 首次入金建议 100-500 USDT
- 做好亏损 8% 的心理准备

## 🚀 部署步骤

### 步骤 1: 安装 sshpass（可选但推荐）

**macOS:**
```bash
brew install sshpass
```

**Linux:**
```bash
apt-get install sshpass  # Debian/Ubuntu
yum install sshpass      # CentOS/RHEL
```

### 步骤 2: 配置部署参数

确保 `.deploy_config` 文件中的服务器信息正确。

### 步骤 3: 执行一键部署

```bash
cd adaptive_grid_trading

# 添加执行权限
chmod +x auto_package.sh upload_to_server.sh one_click_deploy.sh

# 执行一键部署
./one_click_deploy.sh
```

### 部署过程说明

一键部署脚本会自动完成：

1. **打包项目** - 创建压缩包（排除不必要的文件）
2. **上传到服务器** - 使用 SCP 上传
3. **远程部署** - 在服务器上：
   - 停止旧容器
   - 删除旧镜像
   - 解压新代码
   - 构建 Docker 镜像
   - 启动新容器
   - 检查容器状态

### 切换到实盘

测试网验证通过后，切换到实盘：

1. **修改配置文件**
   ```yaml
   exchange:
     testnet: false  # 改为 false
   ```

2. **更新 API 密钥**
   ```bash
   # 编辑 config/.env
   BINANCE_API_KEY=your_live_api_key
   BINANCE_API_SECRET=your_live_api_secret
   ```

3. **重新部署**
   ```bash
   ./one_click_deploy.sh
   ```

### 常见问题

#### Q1: 上传失败

**解决**: 
- 检查服务器密码是否正确
- 检查网络连接
- 安装 sshpass: `brew install sshpass`

#### Q2: Docker 构建失败

**解决**:
```bash
# SSH 到服务器
ssh root@YOUR_SERVER_IP

# 清理 Docker 缓存
docker system prune -f

# 重新构建
cd /root/grid_trading
docker-compose build --no-cache
```

#### Q3: 容器无法启动

**解决**:
```bash
# 查看详细错误
docker logs grid-trading

# 手动启动调试
docker-compose up
```

#### Q4: 无法访问币安 API

**解决**:
```bash
# 在服务器上测试
curl -I https://fapi.binance.com

# 如果无法访问，需要配置代理
# 或使用可以访问币安的服务器
```

#### Q5: 系统异常停止

```bash
# 重启系统
docker start grid-trading

# 检查日志
docker logs grid-trading
```

#### Q6: 飞书报警频繁

- 检查市场波动
- 调整风险参数
- 考虑暂停系统

#### Q7: API 连接失败

- 检查网络
- 验证 API 密钥
- 查看币安状态

### 紧急暂停

docker stop grid-trading

# 确认停止
docker ps -f name=grid-trading

## 🔐 安全建议

### 1. 环境变量安全
- `.env` 文件包含敏感信息
- 不要提交到 Git
- 设置正确的文件权限：`chmod 600 config/.env`

### 2. SSH 安全
- 使用 SSH 密钥代替密码
- 限制 SSH 访问 IP
- 定期更新密码

### 3. Docker 安全
- 使用非 root 用户运行容器（如可能）
- 限制容器资源
- 定期更新基础镜像
