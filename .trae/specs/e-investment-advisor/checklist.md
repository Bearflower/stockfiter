# Checklist

## 配置文件与 CLI

- [ ] `scripts/advisor/config.yaml` 存在且包含所有必要配置项（api、thresholds、position、indices、cache、knowledge_base）
- [ ] `scripts/advisor/config.py` 正确加载 YAML 配置，支持环境变量覆盖（如 `DEEPSEEK_API_KEY`）
- [ ] `scripts/advisor/main.py` 支持 `check`、`analyze`、`chat` 三个子命令
- [ ] 配置文件不存在时，程序使用合理的默认值并输出警告而不崩溃
- [ ] `--output` 参数可将报告保存为 Markdown 文件

## 知识底座加载

- [ ] 启动时自动读取 `docs/distilled/核心观点矿脉.md` 和 `docs/distilled/金句库.md`
- [ ] 蒸馏产物文件不存在时，程序输出明确警告但不崩溃（降级为无知识底座的通用模式）
- [ ] 构建的系统 Prompt 包含：E大投资哲学、估值框架、操作纪律、语言风格
- [ ] Prompt 长度合理控制在 LLM 上下文窗口内，超长时自动精简

## 市场数据获取

- [ ] 通过 akshare 成功获取 6 大指数（上证/深证/沪深300/中证500/创业板/上证50）的 PE/PB 及历史分位数据
- [ ] akshare 不可用时（网络问题、服务不可用），输出明确错误信息而不崩溃
- [ ] 部分指数数据缺失时，仅跳过该指数并继续处理其他指数
- [ ] `--sectors` 参数正确扩展获取行业指数估值
- [ ] 指数列表可从配置文件扩展，无需修改代码

## 市场温度评估

- [ ] PE 分位数据按配置的阈值正确划分为五个温度区间（钻石坑/低估/正常/高估/泡沫）
- [ ] 五区间阈值从 config.yaml 读取，无硬编码
- [ ] 综合全市场温度计算正确（各指数加权或平均）
- [ ] 数据不完整时（部分指数无数据），基于可用数据给出评估并标注置信度

## 仓位建议

- [ ] 仓位映射表从 config.yaml 读取（温度→A股/债券/现金比例）
- [ ] 仓位建议以 A股仓位/债券仓位/现金仓位 三维度呈现
- [ ] 各温度区间的仓位比例总和为 100%

## AI 分析报告

- [ ] LLM 生成的报告包含：今日市场概况、估值温度判断、仓位建议及理由、关注品种、风险提示、金句总结
- [ ] 报告风格体现 E大的语言特色和投资理念
- [ ] API 调用失败后有自动重试机制
- [ ] API 返回异常时不会崩溃，降级为纯数据报告（不含 AI 分析）
- [ ] `check` 子命令不调用 LLM，`analyze` 子命令才调用 LLM

## 交互式问答

- [ ] `chat` 模式启动后先展示市场评估概要，再进入对话循环
- [ ] 支持多轮追问，对话上下文正确维护（包含知识底座 + 市场数据）
- [ ] 输入 `exit`/`quit` 可正常退出对话
- [ ] 上一轮对话历史不被新问题丢失

## 数据缓存

- [ ] 同一天内多次请求市场数据时，第二次从缓存读取，不重复调用 akshare
- [ ] 缓存以 JSON 文件存储在本地，包含时间戳和数据内容
- [ ] 缓存过期后（默认到收盘 15:00 后）自动刷新
- [ ] `--no-cache` 参数可强制跳过缓存重新请求

## 禁止硬编码

- [ ] 所有估值温度阈值均从 config.yaml 读取
- [ ] 所有仓位比例均从 config.yaml 读取
- [ ] 所有指数代码均从 config.yaml 读取
- [ ] 所有 API 配置均从 config.yaml 或环境变量读取
- [ ] 无任何业务逻辑中的固定数值（评分、阈值、延迟时间等）

## 边界情况

- [ ] 蒸馏产物文件缺失时，程序降级但不崩溃
- [ ] akshare 不可用时，`check` 子命令给出明确提示
- [ ] 无网络时，`analyze` 子命令降级为纯数据报告
- [ ] 配置文件完全缺失时，程序使用所有默认值并正常运行
- [ ] 空缓存目录时程序正常初始化

## 整体

- [ ] 模块级测试验证通过（配置加载、知识底座、数据获取、温度计算、缓存、分析引擎）
- [ ] 集成测试验证 `check` 子命令端到端流程
- [ ] 代码注释与日志输出使用中文
- [ ] 新增 Python 依赖已在 `requirements.txt` 中声明
