# Tasks

- [ ] Task 1: 创建项目骨架与配置系统
  - [ ] 1.1 创建 `scripts/advisor/` 目录结构（`__init__.py`、`config.py`、`main.py` 等）
  - [ ] 1.2 编写 `config.yaml` 配置文件，包含：
    - DeepSeek API 配置（base_url、api_key、model）
    - 估值温度阈值（五区间分位阈值）
    - 仓位映射表（温度→A股/债券/现金比例）
    - 指数列表（上证、深证、沪深300、中证500、创业板、上证50）
    - 缓存配置（有效期、路径）
    - 知识底座路径（蒸馏产物文件路径）
  - [ ] 1.3 编写 `config.py` 配置加载模块，支持 YAML 读取、环境变量覆盖、默认值回退
  - [ ] 1.4 编写 `main.py` CLI 入口骨架，支持 `check`、`analyze`、`chat` 三个子命令，使用 argparse

- [ ] Task 2: 实现知识底座加载
  - [ ] 2.1 编写 `knowledge_base.py`，读取 `核心观点矿脉.md` 和 `金句库.md`
  - [ ] 2.2 构建包含 E大投资框架的系统 Prompt（注入投资哲学、估值框架、操作纪律、语言风格）
  - [ ] 2.3 实现 Prompt 长度控制，知识底座过长时自动精简核心观点部分

- [ ] Task 3: 实现市场数据获取
  - [ ] 3.1 编写 `market_data.py`，通过 akshare 获取主要指数 PE/PB 及历史分位数据
  - [ ] 3.2 支持扩展指数（通过配置文件指定指数代码列表）
  - [ ] 3.3 实现网络错误、数据缺失等异常情况的优雅降级处理
  - [ ] 3.4 实现 `--sectors` 参数支持获取行业/板块估值（消费、医药、科技、金融等）

- [ ] Task 4: 实现市场温度评估
  - [ ] 4.1 编写 `temperature.py`，按配置的阈值将 PE 分位划分为五个温度区间
  - [ ] 4.2 实现综合各指数计算全市场温度（加权或平均）
  - [ ] 4.3 编写 `position.py`，根据市场温度映射建议仓位（A股/债券/现金三维度）

- [ ] Task 5: 实现 AI 分析引擎
  - [ ] 5.1 编写 `analyzer.py`，组装 Prompt（知识底座 + 市场数据 + 温度评估 + 仓位建议）
  - [ ] 5.2 调用 DeepSeek API 生成分析报告，处理 API 错误和重试
  - [ ] 5.3 格式化输出结构化报告（市场概况、温度判断、仓位建议、操作方向、风险提示、金句总结）
  - [ ] 5.4 报告输出到终端，同时支持 `--output` 参数保存为 Markdown 文件

- [ ] Task 6: 实现交互式问答
  - [ ] 6.1 编写 `chat.py`，实现交互式对话循环
  - [ ] 6.2 启动时先展示市场评估概要，再进入对话
  - [ ] 6.3 维护对话上下文（多轮对话历史 + 知识底座 + 市场数据），支持追问

- [ ] Task 7: 实现数据缓存
  - [ ] 7.1 编写 `cache.py`，实现本地 JSON 文件缓存
  - [ ] 7.2 同一天内不重复调用 akshare API（以交易日为粒度）
  - [ ] 7.3 缓存有效期可通过配置调整，支持 `--no-cache` 强制刷新

- [ ] Task 8: 测试与验证
  - [ ] 8.1 模块级测试：验证各模块独立功能（配置加载、知识底座、数据获取、温度计算、缓存）
  - [ ] 8.2 集成测试：验证 `check` 命令端到端流程
  - [ ] 8.3 验证所有阈值/参数均从 config.yaml 读取，无硬编码
  - [ ] 8.4 验证网络异常、数据缺失等边界情况的错误处理

# Task Dependencies

- Task 2、Task 3、Task 4 均依赖 Task 1
- Task 4 依赖 Task 3（需要估值数据才能计算温度）
- Task 5 依赖 Task 2、Task 3、Task 4（需要知识底座 + 市场数据 + 温度才能生成报告）
- Task 6 依赖 Task 2、Task 5（基于知识底座和分析引擎实现对话）
- Task 7 依赖 Task 1（独立模块，可与其他任务并行）
- Task 8 依赖 Task 1-7

- Task 2 和 Task 3 可并行开发（互不依赖）

- Task 2.1 和 2.2 可并行
- Task 3.1 和 3.3 可并行
- Task 4.1、4.2、4.3 为顺序依赖
- Task 5.1 和 5.3 可并行（Prompt 组装和输出格式化）
