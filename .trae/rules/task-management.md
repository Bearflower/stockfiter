# 任务管理规范

## /finish 命令

用户输入 `/finish` 时：

1. 检查是否是 `task.md` 中正在进行的任务：
   - **是**：按归档要求进行归档
   - **否**：创建一个已完成的任务，并将会话信息按归档要求持久化存储
2. 调用 `code-document-curator` 检查是否有相关文档需要更新

## 任务状态管理

### 状态切换规则

- 当前任务很可能是正在进行中的任务，如果不是，将进行中的任务挂起
- 如果当前任务是其他未完成的任务，将其设置为进行中并提到最前面
- 如果当前任务不在任务列表或已完成（有进一步需求或需要改进），创建新任务在最前面并标记为进行中

### 任务格式

```
[最后更新:2026-06-01 15:30] 任务标题与描述
```

### 进度汇报要求

当前执行的任务需要概要说明：
- 进展进度
- 当前困难点
- 解决思路
- 尚未解决的问题

## 任务归档

### 完成归档流程

1. 将已完成的任务标记为已完成
2. 将完成过程总结持久化存放到：`.trae/memories/YYYY-MM/DD/HHmm-uuid.md`
3. 已完成任务文档仅记录标题和完成时间，链接到过程 md 文件，保持最小信息量
4. 将已完成任务转到已完成任务文档中

### 归档目录结构

```
.trae/memories/
└── 2026-06/
    └── 01/
        └── 1530-a1b2c3d4.md    # 时间-uuid.md
```
