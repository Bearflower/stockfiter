# 任务管理规范

> **Codex 适配（优先于本文其余历史内容）：** `/finish` 仅表示归档仓库内已完成的工作记录，不等于归档 Codex 任务。优先采用仓库已有任务记录格式；不存在时不要凭空创建并行任务系统。下文的 Trae 会话、`task.md`、`code-document-curator` 和 `.trae/memories` 为历史参考，当前环境不存在时不得伪造调用。

## /finish 命令

用户输入 `/finish` 时：

1. 检查是否是 `task.md` 中正在进行的任务：
   - **是**：按归档要求进行归档
   - **否**：创建一个已完成的任务，并将会话信息按归档要求持久化存储
2. 检查是否有相关文档需要更新；Trae 专属工具不可用时使用当前 Codex 的文档检查能力

## 任务状态管理

### 状态切换规则

- 当前任务很可能是正在进行中的任务，如果不是，将进行中的任务挂起
- 如果当前任务是其他未完成的任务，将其设置为进行中并提到最前面
- 如果当前任务不在任务列表或已完成（有进一步需求或需要改进），创建新任务在最前面并标记为进行中

### 任务格式

```
[最后更新:2026-06-01 15:30] 任务标题与描述
```

### 进度汇报要求

当前执行的任务需要概要说明：
- 进展进度
- 当前困难点
- 解决思路
- 尚未解决的问题

## 任务归档

### 完成归档流程

1. 将已完成的任务标记为已完成
2. 仅在用户要求持久化且仓库采用该格式时，将完成过程总结存放到：`.trae/memorics/YYYY-MM/DD/HHmm-uuid.md`
3. 已完成任务文档仅记录标题和完成时间，链接到过程 md 文件，保持最小信息量
4. 将已完成任务转到已完成任务文档中

### 归档目录结构

```
.trae/memories/
└── 2026-06/
    └── 01/
        └── 1530-a1b2c3d4.md    # 时间-uuid.md
```
