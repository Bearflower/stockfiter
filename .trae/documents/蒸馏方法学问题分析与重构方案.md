# 蒸馏方法学分析：为什么观点库是"正确的废话"

## 0. 数据特征（关键发现）

```
总篇数: 294
  ├─ 发车帖/投资计划: 109 (37.1%)  ← 交易记录，非观点表达
  ├─ 微博精选:        183 (62.2%)  ← 每条含10-30条短微博，多观点混杂
  └─ 独立文章/问答:     2  (0.7%)  ← 真正的长文观点
```

**结论：99.3% 的输入不是"一篇表达一个核心观点的文章"。**

---

## 1. 现行方法学的三个根本错误

### 错误1：无视输入类型差异，"一刀切"式提炼

所有 294 篇走同一 pipeline：

```
blog原文 → [summarizer] → 100字核心观点摘要 → [analyzer] → 核心观点矿脉 → [opinion_extractor] → 20条观点
```

但不同类型的内容差异巨大：

| 类型 | 一篇内容示例 | 现行处理 | 应该是 |
|------|------------|---------|--------|
| **发车帖** (109篇) | "150计划卖出一份建信中证500，收益率76%..." | 提取"核心观点：作者在150计划卖出一份..." | 提取**操作记录**：品种+动作+收益率+时间+原因 |
| **微博精选** (183篇) | 每月合集含20+条微博，有讲估值的、有讲心态的、有骂市场的 | 提取1条摘要覆盖全部 | 按单条微博**分条提取**或至少提取**多个观点** |
| **独立文章** (2篇) | 真正有完整论述逻辑的长文 | 提取核心观点（合理） | 深度摘要（基本合理） |

**结果**：109 条发车帖的摘要变成了"作者卖出了XX，收益率XX"的流水账，183 条微博精选的摘要变成了一句概括 20 条微博的"万金油"句子。analyzer 从这些摘要中提取"反复强调的观点"时，得到的自然是最安全的通用结论。

### 错误2：输入输出端的逻辑错配——把"操作行为"当"观点"提炼

发车帖（37.1%）的本质是**操作记录**，不是**观点表达**。

```
原文："150计划卖出一份建信中证500(000478)，收益率76%..."
      ↑ 这是一个 action
摘要："作者在150计划中卖出一份建信中证500，收益率约76%，并计划今年内清仓"
      ↑ 这是一个 rephrase，不是"核心观点"
```

**问题**：当109篇发车帖的摘要被当成"核心观点"喂给 analyzer 时，analyzer 在 294 条中输入中看到的是：
- 109条 "卖出了XX" 类摘要（高频信号）
- 少量的"逆向投资"、"估值判断"类摘要（低频信号）

**analyzer 的 prompt 要求"提取最反复强调的观点"→ 自然输出了最安全的通用原则。**

### 错误3：微博精选被当成"一篇文章"处理

183 篇微博精选（62.2%）中，每篇包含 10-30 条 E 大在不同日期、不同市场环境下发的短微博。

以 `2025年9月长赢指数投资计划（一）` 类文件为例——这类微博精选可能同时包含：
> "今天卖出一份XXX"（交易操作）
> "市场又跌了，保持耐心"（心态）
> "估值已进入低估区"（市场判断）

但在 summarizer 里被压缩成**一条 100 字摘要**，选择性地丢失了 90% 的内容。然后 analyzer 只能在丢失了 90% 信息的摘要上进行"深度分析"。

## 2. 下游影响：opinion_matcher 为什么匹配不出好结果

当前观点库产出 20 条通用观点：

```
"投资是概率游戏，核心是计算值博率"         → market_condition: 通用
"资产配置是唯一的免费午餐"                  → market_condition: 通用
"坚持逆向投资，在资产惨淡时买入，众星捧月时卖出" → market_condition: 市场恐慌
"买贵是投资中最大的风险"                    → market_condition: 高估区
```

当 opinion_matcher 拿到当前市场状态（**PE分位均值 99.3%，泡沫**）去匹配时：

| 观点 | market_condition | 匹配度 |
|------|----------------|--------|
| "买贵是投资中最大的风险" | 高估区 | ✅ 唯一能匹配的 |
| "坚持逆向投资..." | 市场恐慌 | ❌ (现在是泡沫不是恐慌) |
| 其余18条 | 通用 | ⚠️ 都能用但都不特指 |
| **近期操作记录** (如"6月连续卖出建信500、红利") | **不存在** | ❌ |

**日报输出的"E大说过"段落：**
> 💬 E大说过
> > 买贵是投资中最大的风险，高位买入需低位多买摊低成本，否则长期收益极低。
> > *——当前估值处于高位*

这条观点虽然"正确"，但缺乏时效性和针对性。理想的匹配应该是：

> 💬 E大说过
> > 6月我们卖出了建信500（收益76%）和富国中证红利（收益82%），在A股红利指数长期优于宽基。这次卖红利不是减仓红利，是换仓到成本更低的同类指数。
> > *——6月操作映射了当前高估市场的策略*

> > 买得那么低尚且要熬8年才赚钱，买高了会怎样？现在市场上又出现估值80+的宽基指数了。
> > *——当前市场估值与E大6月警示一致*

## 3. 新方法学设计

### 核心理念

**不要提炼"E大相信什么"，要提炼"E大做了什么 + 说过什么 + 原则是什么"**

将蒸馏链路改为**三通道并行**：

```
输入分类 → 三通道提取 → 合并输出 → 分场景匹配
```

### 通道1：操作记录通道（处理发车帖）

| 输入 | 输出 | 用途 |
|------|------|------|
| "150计划卖出一份建信中证500，收益率76%" | `{action: "卖出", fund: "建信中证500", yield: "76%", time: "2026-06", plan: "150", memo: "只剩2份，今年清仓"}` | 用于日报展示近期操作动态 |

- 从 109 篇发车帖提取结构化操作记录
- 按时间排序，形成"操作时间线"
- 可汇总统计（如"6月共卖出3次建信500"）

### 通道2：近期市场判断通道（处理微博精选 + 发车帖中的评论）

| 输入 | 输出 | 用途 |
|------|------|------|
| 微博中的各条判断 | `{observation: "市场上又出现估值80+的宽基指数", time: "2026-06", context: "高估区"}` | 用于日报匹配当前市场状态 |

- 微博精选按单条微博分割，每条单独提取
- 提取 E 大对当前/近期市场的具体判断
- 每条附带时间戳和市场语境标签

### 通道3：通用原则通道（处理所有内容）——保留现有方案

| 输入 | 输出 | 用途 |
|------|------|------|
| 所有内容 | 通用投资原则（如"资产配置是免费午餐"） | 用于补充匹配，当通道1/2无匹配时兜底 |

### 输出合并

三个通道的输出合并为一个"增强型观点库"，每条增加 `source_type` 字段：

```json
[
  {"opinion": "6月卖出建信中证500，收益率76%", "source_type": "operation", "time": "2026-06"},
  {"opinion": "红利指数在A股长期超越宽基", "source_type": "market_observation", "time": "2026-06"},
  {"opinion": "投资是概率游戏...", "source_type": "principle", "time": null}
]
```

### 匹配逻辑升级

opinion_matcher 的匹配逻辑改为：

1. 先查通道2（近期市场判断）：找出 time 在最近3个月内且 market_condition 与当前匹配的
2. 再查通道1（操作记录）：找出 time 在最近3个月内且操作方向与当前建议一致的
3. 最后查通道3（通用原则）：如果前两者不足，用通用原则补充

## 4. 修改方案（实施路径）

### Phase 1：修改 summarizer 支持多类型处理

## 5. 预期效果

修改后，日报的"E大说过"段落会变为：

```
💬 E大近期操作
> 6月连续卖出建信中证500（收益76%→清仓）、富国中证红利（收益82%→换仓）。
> 这是2026年自2月以来的第8次卖出操作，前期买入品种基本清仓完毕。

💬 E大近期判断
> "买得那么低尚且要熬8年才赚钱，买高了会怎样？"
> "市场上又出现估值80+的宽基指数了。"
> "红利指数在A股几乎是最适合个人投资者的品种。"

💬 E大金句
> "卖出比买入难，基于估值和纪律止盈，落袋为安。"
> "控制回撤比追求收益更重要，熊市少亏甚至不亏，牛市跟上指数即可。"
```

这样的内容才真正对日报读者（跟随E大策略的投资者）有价值——他们能看到E大**最近在做什么、怎么判断当前市场、以及一贯的原则是什么**。
